「今いくらになっているのか分からない」というのは、海外積み立ての相談でとても多いお悩みです。担当のIFAと連絡が取れなくなっていても、契約者本人であれば、保険会社から明細を取り寄せたり、オンライン口座で確認したりできるのが一般的です。ここでは、明細の取り寄せ方と、明細に出てくる主な項目の意味を説明します。

## この手続きについて

保険会社は、年に1回ほど年次明細（Annual Statement）を送っているのが一般的です。それとは別に、契約者が求めれば、その時点の評価額を示す書類（Valuation、Policy Statement など）を出してもらえます。解約したときに戻る金額を知りたい場合は、解約返戻金の見積もり（Surrender Value Quotation）を依頼します。

多くの保険会社は、契約者向けのオンライン口座（オンラインサービス）も用意しています。登録すれば、評価額、保有しているファンド、払い込みの履歴などをいつでも確認できます。

## 準備するもの

- 証券番号（Policy Number）
- 契約者の氏名、生年月日、登録している住所（本人確認に使われます）
- 保険会社に登録しているメールアドレス（そのアドレスから依頼すると本人確認が進みやすくなります）

## 明細を取り寄せる流れ

1. **何が知りたいかを決める。** 今の評価額だけでよいのか、解約返戻金の見積もりもほしいのか、過去の払い込み履歴も必要なのかを決めておくと、一度の依頼で済みます。
2. **保険会社に依頼する。** 登録のメールアドレスからメールで依頼するか、署名入りのレターを送ります。電話で受け付ける会社もあります。
3. **本人確認に答える。** 登録情報との照合や、追加の書類を求められることがあります。
4. **明細を受け取る。** メール（パスワード付きのPDFなど）や郵送で届きます。

## オンライン口座に登録する流れ

1. **保険会社のサイトで、契約者向けの登録ページを探す。** 「Online Services」「Policyholder Login」などの名前になっていることが多いです。
2. **証券番号などを入力して登録を申し込む。** 本人確認のため、アクティベーションコードが郵送やメールで届く仕組みの会社もあります。郵送の場合、届くまでに日数がかかります。
3. **ログインして登録情報を確認する。** 住所やメールアドレスが古いままなら、あわせて変更手続きをしておきましょう。

## 明細に出てくる主な項目

| 英語の表記 | 意味 |
| --- | --- |
| Policy Value / Current Value | 評価額。今の時価で計算した、保有ファンドの合計 |
| Surrender Value / Cash-in Value | 解約返戻金。いま解約した場合に戻る金額。評価額より少ないことが多い |
| Initial Units / Initial Account | 初期口座。契約の最初の期間に払ったお金が入る部分 |
| Accumulation Units / Accumulation Account | 貯蓄口座。初期口座の期間のあとに払ったお金が入る部分 |
| Premiums Paid / Total Contributions | これまでに払い込んだ保険料の合計 |
| Fund / Unit Price / Units Held | 保有しているファンド名、1口あたりの価格、保有口数 |
| Charges / Fees | 差し引かれた手数料 |
| Premium Status | 払い込みの状況（払い込み中、一時停止中など） |

項目の名前は会社によって違います。分からない項目があれば、保険会社に意味を尋ねても差し支えありません。

## つまずきやすい点

- **評価額がそのまま戻ってくると思ってしまう。** 実際に戻るのは解約返戻金です。特に契約から日が浅いうちは、評価額との差が大きくなりがちです。
- **通貨を見落とす。** 明細は契約の通貨（米ドル、ポンド、ユーロなど）で書かれています。円に換算するときは、その日の為替レートで計算してください。
- **登録のメールアドレスが古い。** 古いアドレスにしか送れないと言われることがあります。先に連絡先の変更が必要になる場合があります。
- **オンライン口座の登録に必要なコードが古い住所に届く。** 住所の変更を先に済ませておきましょう。

## かかる期間の目安

オンライン口座に登録済みなら、その場で確認できます。メールで依頼した明細は数日から2週間ほど、郵送の場合は国際郵便の日数を含めて2〜6週間ほどかかることがあります。あくまで目安です。

> 保険会社によって書式・手順は異なります。最新の書式は各社のサイトまたはサポート窓口でご確認ください。
