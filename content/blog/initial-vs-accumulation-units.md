評価書（ステートメント）を見て、「初期口座」と「積立口座」という2つの数字があり、何が違うのか分からないという方は多いと思います。結論から言うと、初期口座（イニシャルユニット：最初の期間に払った分。手数料が重い）は契約初期の積立金で買われる特別な口数（ファンドの持ち分の単位）で、手数料と引き出しの制限が重いもの、積立口座（アキュムレーションユニット：初期口座の後に払った分）はその後に買われる通常の口数です。

## 初期口座と積立口座は、そもそも何が違うの？

違いは「いつ払ったお金で買われたか」です。契約してから一定の期間（初期口座期間）の積立金は初期口座の口数に、それ以降の積立金は積立口座の口数に充てられます。

| 項目 | 初期口座 | 積立口座 |
| --- | --- | --- |
| 買われる時期 | 契約初期の一定期間 | 初期口座期間の後 |
| 英語の表記の例 | Initial units / Establishment units | Accumulation units / Standard units |
| 手数料 | 通常の手数料に加え、初期口座専用の手数料が満期まで続くことが多い | 通常の手数料のみ |
| 引き出し | 原則として対象外 | 条件を満たせば引き出しの対象 |
| 途中解約 | 大きな解約控除（早く解約したときに差し引かれる費用）がかかる | 解約控除がかからない（または小さい）ことが多い |

初期口座期間の長さは商品と契約期間によって決まります。たとえばRL360のクォンタムの[重要事項説明書（2016年頃の版）](https://tailormadepensions.eu/wp-content/uploads/2017/01/RL360-Quantum-Savings-Plan-Key-Features.pdf)では、契約期間5〜18年なら18か月、24年以上なら24か月と定められています。

## 初期口座には、どんな手数料がかかるの？

初期口座には、その価値に対して毎月手数料がかかる設計が多く見られます。上記のクォンタムの資料では、初期口座の価値に対して月0.50％の手数料が、積立期間を通して差し引かれると書かれています。年に直すと約6％です。

これとは別に、プラン全体にかかる管理手数料（クォンタムでは評価額の月0.125％）と、毎月の固定手数料もあります。新しい商品であるRL360の[Regular Savings Plan のFAQ](https://www.rl360.com/generic/downloads/RS32-Frequently-Asked-Questions.pdf)でも、初期口座（Establishment units）の価値に対して月0.50％の手数料がかかる仕組みが説明されています。

仮に初期口座の価値が9,000ドルのまま変わらないとすると、月0.5％の手数料は年540ドルです（運用による増減は考慮なし）。初期口座の手数料は、保険会社がIFAへの手数料などの初期費用を、長い期間をかけて回収する仕組みと考えると理解しやすいでしょう。手数料全体の構造は[海外積み立て商品の手数料の仕組み](/blog/offshore-plan-fees-explained)で整理しています。

## 引き出しや解約では、どう扱いが違うの？

引き出せるのは原則として積立口座の部分です。初期口座は引き出しの対象外で、途中解約するときは解約控除が差し引かれます。

クォンタムの例では、初期口座期間中に解約すると返戻金はなく、実質100％の解約控除になると明記されています。初期口座期間が終わった後も、積立期間の終わりまでは初期口座の価値に解約控除がかかり、その割合は満期までの残り年数が長いほど大きくなります。一方、満期まで続ければ、残った初期口座は積立口座と同じ扱いに変わる仕組みです。

この仕組みのため、契約から日が浅いほど、解約したときに戻る金額は払い込み額より大きく少なくなりがちです。

## 評価書で見るときのポイントは？

評価書では、次の3つを分けて確認すると状況がつかみやすくなります。

1. **評価額（Fund value）**：初期口座と積立口座を合わせた価値
2. **解約返戻金（Surrender value：解約したときに戻ってくるお金）**：今解約したときに実際に戻る金額
3. **積立口座の価値**：引き出しの対象になる部分

評価額と解約返戻金の差が、主に初期口座にかかる解約控除です。この差を知らずに「評価額が全部戻る」と考えていると、判断を誤りやすくなります。

## 満期まで続けると、初期口座はどうなるの？

満期まで続けた場合、初期口座は積立口座と同じ扱いに変わるのが一般的です。RL360のクォンタムの資料では、積立期間の終わりに、残っている初期口座はすべて1対1の割合で積立口座に切り替えられると説明されています。満期時には、初期口座に対する解約控除はかかりません。

一方、積立額を途中で増やした場合は注意が必要です。同じ資料では、増額した分ごとに新しい初期口座期間と解約控除が設定されるとされています。

| 場面 | 初期口座の扱い |
| --- | --- |
| 契約当初 | 最初の18〜24か月の積立金が初期口座になる |
| 途中で増額 | 増やした分に、新しい初期口座期間が設定される |
| 途中で解約 | 初期口座に、満期までの残り年数に応じた解約控除がかかる |
| 満期まで継続 | 残った初期口座が積立口座に切り替わる |

このように、初期口座は「契約の初めだけの話」ではなく、満期まで影響が続く仕組みです。評価書を見るときは、初期口座の価値が今どれくらいあるのか、それが解約返戻金とどう関係しているのかを、あわせて確認すると全体像がつかみやすくなります。

## まとめ

初期口座は契約初期の積立金で買われる口数で、満期まで続く手数料と、引き出し・解約の強い制限があります。積立口座は初期口座期間の後に買われる通常の口数で、引き出しの対象になります。条件は商品や契約時期によって違うため、ご自身の契約条件書と評価書で確認しましょう。評価書の見方を整理したい方は[AIチャット](/chat)もご利用ください。
