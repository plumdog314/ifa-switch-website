「周大福人壽（旧FTLife）の貯蓄保険を解約したいが、どの書類を使えばいいのか分からない」。そんなときは、まず公式の書式集で何が公開されているかを知っておくと動きやすくなります。結論から言うと、基本プランの全部解約には「Surrender Form（退保申請書）」が必要とされていますが、この書式は公式サイトに掲載がなく、会社への確認が必要です。一部の引き出しには、公開されている専用の書式があります。

会社の沿革は[FTLife（富通保險）ってどんな会社？](/blog/what-is-ftlife)で整理しています。この記事は、解約するかどうかを勧めるものではありません。

## 全部解約するには、どの書類が必要なの？

「Surrender Form（退保申請書）」という書類が必要です。CTF Lifeの[Change Form（更改申請書）](https://www.ctflife.com.hk/pdf/en/support/download/CS0031.pdf)の注記に、基本プランを終わらせる（Termination of a basic plan）場合はSurrender Formを出すように、と書かれています。

ただし、本記事の確認時点（2026年11月）で、[公式サイトの書式集](https://www.ctflife.com.hk/en/support/download)にSurrender Formは載っていませんでした。最新の書式、署名のルール、添付書類、提出先は、カスタマーサービスか担当の保険代理人（Insurance Agent）・保険ブローカー（Insurance Broker）に確認してください。

## 解約の前に、何を確認しておけばいいの？

受け取れる金額の見込みと、その内訳を確認しておくと安心です。たとえば販売中の「MyWealth Savings Insurance Plan 2 (Premier)」の[商品パンフレット](https://www.ctflife.com.hk/pdf/en/mywealth-savings-2-premier-insurance-plan-brochure.pdf)では、解約時の受取額は次の合計から借入を差し引いた額とされています。

| 内訳 | 保証の有無 |
| --- | --- |
| 保証解約返戻金（Guaranteed Cash Value） | 保証あり |
| 積み立てられた復帰ボーナス（Reversionary Bonus）の現金価値 | 保証なし |
| 最終ボーナス（Terminal Bonus）の現金価値 | 保証なし |
| 安定資産口座（Stable Asset Account）の積立額 | 商品の条件による |
| 契約者貸付などの借入（Indebtedness） | 差し引かれる |

同じパンフレットには、早く解約すると大きな損失になることがある、とも書かれています。受取額の考え方は商品と契約時期によって違うため、ご自身の約款を確認してください。カスタマーサービスでは、ホットライン（852）2866 8898とメール ctflife.csc@ctflife.com.hk が案内されています（[連絡先のページ](https://www.ctflife.com.hk/en/support/contact-us/contact-details)）。解約前の確認点は[解約する前に確認しておきたい5つのこと](/blog/before-surrender)も参考にしてください。

## 一部だけ引き出すときは、どの書式を使うの？

貯蓄型の契約では「Policy Account Value Withdrawal Request Form（保單戶口價值提取申請書）」を使います。[この書式](https://www.ctflife.com.hk/pdf/tc/support/download/cash-endowment-withdrawal-request-form.pdf)では、引き出す口座を指定するか、決められた順番で引き出すかを選びます。決められた順番は次のとおりです。

1. 保険料の預かり金（Policy suspense）
2. キャッシュクーポン（Cash coupons）
3. 支払い済みの配当とその利息
4. 積み立てた復帰ボーナスと関連する最終配当
5. 保険金額を減らして引き出す（部分解約）

書式の注記では、5番目の方法は「Regent」「MyWealth」「Fortune Saver」などの特定シリーズだけが対象です。保険金額を減らすと、保証解約返戻金や将来の配当・ボーナスも減り、減らした部分は元に戻せないとされています。投資型の契約には別の「Investment Choice Withdrawal Request Form」があります。一部引き出し全般は[積み立てから一部引き出したいときの手続き](/blog/partial-withdrawal)で解説しています。

## 日本に住んでいても、お金を受け取れるの？

受け取れます。引き出しの書式では、受け取り方法として次の3つが示されています。

| 方法 | 書式に書かれた条件 |
| --- | --- |
| 電信送金（Telegraphic Transfer） | 海外の契約者向け。銀行手数料がかかる |
| 香港の即時送金（FPS） | 香港の銀行口座・香港ドルのみ、100万香港ドルまで |
| 小切手 | 香港ドル、米ドル（米ドル契約のみ）など |

電信送金を使う場合は、[Authorization for Payment Instruction](https://www.ctflife.com.hk/pdf/en/support/download/authorization-for-payment-instruction.pdf)の書式で送金先口座を登録します。この書式には、支払いは契約の通貨で行うこと、何らかの理由で送金できなかった場合は香港ドルの小切手を登録住所に郵送することが書かれています。登録住所が古いままだと小切手が届かないため、先に[住所変更](/blog/ftlife-change-address)を済ませておくと安心です。

## 書類を出すときに気をつけることは？

署名は、申込書や会社の最新の記録と同じものにする必要があります。書式に、署名は申込書または会社の最新の記録と一致しなければならないと書かれています。書式には証人または保険代理人・ブローカーの署名欄もあります。

書式には、スマートフォンのアプリ「CTF Life」から手続きを申し込めるという案内も載っています。どの手続きがアプリでできるかは、[オンラインサービスのページ](https://www.ctflife.com.hk/en/support/online-service/e-service)とアプリ内で確認してください。申し込みから着金までの日数は、今回確認した公式資料には書かれていませんでした。

利益が出た場合の税金は[海外積み立てを解約したときの確定申告の考え方](/blog/tax-on-surrender)をご覧ください。

## まとめ

周大福人壽（旧FTLife）で基本プランを全部解約するには「Surrender Form」が必要ですが、公式サイトには掲載がないため、会社か担当者から最新版を取り寄せます。一部の引き出しには公開の書式があり、海外の契約者は電信送金で受け取れます（銀行手数料あり）。受取額は保証部分と非保証部分の合計から借入を引いた額です。書類の内容を整理したい方は[AIチャット](/chat)を、個別に相談したい方は[お問い合わせ](/contact)をご利用ください。
