海外積み立てを解約したとき、「税金はかかるのか」「確定申告は必要なのか」と迷う方は多くいます。特に、海外の保険会社からは日本のような支払いの通知が届かないため、何をすればいいのか分かりにくいものです。結論から言うと、利益が出た場合は一般に一時所得として申告が必要になることがあり、損失が出た場合は課税されません。ここでは基本の考え方を整理します。

## 解約返戻金は、どの所得になるの？

保険料を払った本人が解約返戻金を受け取る場合、一般に一時所得として扱われる考え方が基本です。[国税庁 No.1755](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1755.htm)では、生命保険の満期保険金などを一時金で受け取った場合、保険料を払った人と受け取る人が同じなら、一時所得として所得税の対象になると説明されています。

海外の保険会社との契約も、この考え方を基本に整理されることが多いです。ただし、契約の性質（生命保険契約に当たるか、キャピタル・リデンプション型と呼ばれる形かなど）によって扱いが変わる可能性があります。また、保険料を払った人と受け取る人が違う場合は、所得税ではなく贈与税などの対象になることがあります。

## 一時所得は、どう計算するの？

一時所得は次の式で計算します（[国税庁 No.1490](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1490.htm)）。

> 一時所得の金額 ＝ 受け取った金額 － 払い込んだ金額 － 特別控除（最高50万円）

そして、ほかの所得と合算するときは、この金額の2分の1が対象になります。

仮の数字で計算の流れを示します（ほかに一時所得はないものとし、円換算後の金額とします）。

| 項目 | 金額 |
| --- | --- |
| 受け取った解約返戻金 | 600万円 |
| 払い込んだ金額の合計 | 400万円 |
| 差額 | 200万円 |
| 特別控除 | 50万円 |
| 一時所得の金額 | 150万円 |
| ほかの所得と合算する金額（2分の1） | 75万円 |

この75万円が給与などの所得と合算され、税率は全体の所得の大きさで決まります。これは計算の流れを示した例で、実際の税額はご自身の所得全体によって変わります。

## 損失が出た場合は、どうなるの？

払い込んだ金額より受取額が少ない場合、一時所得はマイナスになり、課税はされません。初期口座期間中や契約初期の解約では、解約控除によって損失が出ることも珍しくありません。

ただし、その損失を給与所得などほかの所得と相殺（損益通算）することはできません。[国税庁 No.2250](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2250.htm)でも、一時所得の損失はほかの所得から差し引けない扱いとされています。元本割れで解約した場合の考え方は[元本割れで解約した場合、税金や申告はどうなる？](/blog/tax-loss-on-surrender)でくわしく解説しています。

## 確定申告が必要かどうかは、どう判断するの？

次の順番で考えると整理しやすくなります。

1. **利益が出ているか**：受け取った金額が払い込んだ金額を上回っているか
2. **特別控除を超えるか**：利益が50万円（同じ年のほかの一時所得と合計）を超えるか
3. **申告が必要な条件に当たるか**：会社員の場合、給与以外の所得の合計が20万円を超えるか（[国税庁 No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm)）など

確定申告が不要な場合でも、住民税の申告が必要になることがあります。条件は人によって違うため、最終的には税理士や税務署に確認しましょう。

## 外貨建ての場合は、何に気をつけるの？

外貨建てのプランでは、受け取った金額も払い込んだ金額も円に換算して計算します。為替レートが払い込み時と受け取り時で違うため、外貨では損失でも円では利益になる、またはその逆になることがあります。

そのため、次の記録を残しておくことが大切です。

- 毎回の払い込みの日付・金額・円換算額（カードの利用明細など）
- 解約返戻金の受取日・金額（保険会社の書面）
- 日本の銀行で受け取ったときの入金記録と為替レート

なお、100万円を超える国外からの送金を受け取ると、金融機関から税務署へ[国外送金等調書](https://www.nta.go.jp/about/introduction/torikumi/report/2025/04_4.htm)が提出されます。解約そのものを考えている方は、手続きの前に[解約する前に確認したい5つのこと](/blog/before-surrender)もご覧ください。

## 確定申告では、どんな書類をそろえるの？

海外の保険会社からは、日本の保険会社のような税務向けの書類が届かないことが多いため、自分で根拠となる書類をそろえる必要があります。一般的には、次のようなものを準備します。

| 書類 | 何を示すか |
| --- | --- |
| 保険会社の解約の通知・支払いの明細 | 解約日、解約返戻金の金額、通貨 |
| 銀行の入金記録 | 受け取った日、円で受け取った金額 |
| 払い込みの記録 | 払い込んだ金額の合計と、それぞれの円換算額 |
| 契約書類 | 契約者・受取人・契約の形 |
| 為替レートの記録 | 円換算に使ったレートとその根拠 |

払い込みの記録は、25年前後の長い契約では特にそろえにくくなります。クレジットカードの利用明細の保存期間が過ぎている場合は、保険会社に払い込みの履歴を依頼できるか問い合わせてみましょう。

一時所得は、確定申告書の一時所得の欄に記入します。計算の根拠になる書類は、申告書と一緒に保管しておくことが大切です。書類がそろわない部分があるときや、円換算の方法に迷うときは、申告の前に税理士や税務署に相談すると安心です。

## まとめ

海外積み立ての解約返戻金は、一般に一時所得として扱われる考え方が基本です。利益から特別控除50万円を差し引き、その2分の1がほかの所得と合算されます。損失が出た場合は課税されませんが、ほかの所得とは相殺できません。外貨建ての場合は円換算の記録を残し、個別の申告は税理士に確認しましょう。
