「何年も使っていないハンセン銀行（恒生銀行）の口座が、まだ使えるか分からない」「日本からアプリにログインできない」。海外積み立ての支払いや受け取りに香港の口座を使っていた方から、よく聞く悩みです。結論から言うと、ハンセン銀行の口座は24か月取引がないと休眠になります。ただし、条件がそろえばオンラインで再開できます。

この記事では、ハンセン銀行の公式の[FAQ](https://www.hangseng.com/en-hk/personal/banking-services/useful-information/faq/)や申込書をもとに、本記事の確認時点（2026年11月）の手続きを整理します。

## どうなると休眠口座になるの？

お客さま自身の取引が一定期間ないと、休眠口座になります。統合口座（Integrated Account）や普通預金などは、その期間が24か月です。

FAQでは、休眠口座を「inactive / dormant account」と呼んでいます。休眠になると、再開するまで入金や出金が制限されます。FAQに載っている口座の種類と期間は次のとおりです。

| 口座の種類 | 休眠にならないための条件 |
| --- | --- |
| 統合口座 | 24か月に1回以上の取引 |
| 香港ドルの普通預金・当座預金、外貨の普通預金 | 24か月に1回以上の取引 |
| 人民元の普通預金、米ドル・人民元の当座預金 | 24か月に1回以上の取引 |

取引とは、引き出し、公共料金などの支払い、送金の受け取りや送り出しなどです。ATM、オンライン、窓口のどれで行ってもかまいません。利息や手数料の引き落としは取引に数えられません。

## 休眠口座に手数料はかかるの？

公式資料には、手数料がかかる場合があると書かれています。ただし、金額は確認できませんでした。

[個人口座の取り扱いの説明資料](https://www.hangseng.com/content/dam/hase/rwd/personal/pdfs/Descriptive-information-of-Personal-Account-Operations.pdf)には、休眠口座の残高が所定の最低残高を下回ると、半年ごとに手数料が引かれると書かれています。残高が手数料に足りないときは残高がすべて引かれ、残高がゼロになると口座は自動で閉じられます。口座が休眠になったときは、銀行から郵便で知らせが届くとされています。一方、2026年7月1日適用の[料金表](https://www.hangseng.com/content/dam/wpb/hase/config/bde/pws/personal/servicecharges/pdfs/tariff_personal_e.pdf)には、休眠口座の手数料の項目が見当たりませんでした。ご自身の口座が対象になるかは、ハンセン銀行に確認してください。

## 休眠口座は、どうやって再開するの？

条件を満たしていれば、オンラインで再開できます。条件は、銀行に有効な携帯番号が登録されていることと、Mobile Security Key（アプリの中の認証機能）などが使える状態であることです。

FAQによると、Personal e-Bankingかアプリの「Reactivate Inactive Account」のサービスから申し込みます。1回に選べるのは3口座までで、それ以上は分けて申し込みます。

月曜から金曜は午後9時まで、土曜は午後6時までに申し込めば、1営業日で処理されます。それ以降や祝日は2営業日です。結果はSMSやメールで届きます。

オンラインが使えない場合は、次の方法があります。

| 方法 | 内容 |
| --- | --- |
| 電話 | FAQの案内は顧客サービス（852）2822 0228。申込書では24時間の電話バンキングも挙げられ、PINがない場合は香港のATMで取得するよう書かれている |
| 支店 | 香港の支店で手続き |
| 郵送 | [再開の申込書（OSCM352）](https://www.hangseng.com/content/dam/hase/config/bde/pws/personal/pdfs/OSCM352.pdf)に署名した身分証明書のコピーを付け、GPO Box 3013, Hong Kong へ送る |

申込書には、通常3〜5営業日で処理すると書かれています。携帯番号の変更も同時に行う場合は、10営業日ほどかかります。申込書1枚で再開できるのは1口座です。郵送の場合は手数料がかかり、料金表の該当項目は1件HK$150です。すべての口座が休眠の場合は、FAQで「Customer Enquiries Form」から申し込むよう案内されています。

## 日本からログインできないときは、何を確認する？

まず、Mobile Security Keyを入れたスマートフォンと、銀行に登録した携帯番号を確認します。ハンセン銀行のログインは、この2つが前提になっています。

[Mobile Security Keyのページ](https://www.hangseng.com/en-hk/personal/digital/personal-mobile-app/mobile-security-key/)とFAQの内容を、困りごと別にまとめます。

| 困りごと | 公式の案内 |
| --- | --- |
| 海外の携帯番号でSMSが届くか | 海外の番号を登録していれば、その番号にSMSを送る。受け取れる環境かは自分で確認する |
| SIMや電話番号を変えた | Mobile Security Keyは端末にひもづくため再設定は不要。番号は銀行の記録を更新する |
| スマートフォンを買い替えた | 古い端末に表示するQRコードを新しい端末で読み取る |
| 古い端末が手元にない | 香港IDなどを持つ人は、身分証と自撮りで新しい端末を登録できる |
| 端末をなくした | すぐに（852）2822 0228へ連絡する |
| パスワードを忘れた | ログイン画面の「Forgot your password?」から再設定する。秘密の質問を設定していない場合は、電話か支店で有効にする |

新しい端末を登録した後は、一部のサービスが一時的に止まります。香港のハンセン銀行かHSBCのATM、または電話バンキングのPINを使った電話で、本人確認をすると解除できます。なお、身分証と自撮りによる登録は香港IDなどを持つ人向けの手順です。パスポートで口座を開いた方の手順は詳しく書かれていないため、ハンセン銀行に確認してください。物理的なセキュリティ機器（Security Device）は、2022年7月1日から新しく発行されていないとFAQに書かれています。

連絡先の変更は、アプリやオンラインで行えます。ただし、Mobile Security Keyと有効な携帯番号かメールアドレスが必要です。住所変更の考え方は[住所が変わったときの手続き](/blog/change-of-address)も参考にしてください。

## まとめ

本記事の確認時点（2026年11月）では、ハンセン銀行の統合口座などは24か月取引がないと休眠になり、入出金が制限されます。有効な携帯番号とMobile Security Keyがあれば、オンラインで1〜2営業日で再開できます。どちらも使えない場合は、電話、支店、郵送で手続きします。日本からのログインでは、海外の携帯番号の登録と、端末の状態が鍵になります。口座の情報が日本の税務署に届く仕組みは[CRS（共通報告基準）とは？](/blog/crs-explained)で解説しています。
