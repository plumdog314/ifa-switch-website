「年利9％保証です」「元本割れはありません」と勧められて、心が動いた方もいるかもしれません。結論から言うと、株式や投資信託の運用で高い利回りを「保証」すると言い切る話は、詐欺や違法な勧誘を強く疑うべき典型的なサインです。

## なぜ「高利回りの保証」はありえないのですか？

株式や投資信託の値段は毎日動くため、年9％のような高い利回りを確実に約束することは、通常できません。たとえば世界の株式市場でも、2008年の金融危機や2020年のコロナショックのように、1年で大きく下がる年は実際にありました。

本当に年9％を確実に稼げる方法があるなら、銀行や大手の運用会社がとっくに使っているはずです。利回りが高いほどリスクも大きくなるのが、投資の基本的な関係です。

| よく聞く言葉 | 実際に考えるべきこと |
| --- | --- |
| 年利9％保証 | 誰が、どの資産で、どう保証するのか文書で示されているか |
| 元本割れなし | 価格が動く資産なら、元本割れは起こりうる |
| 今だけ・あなただけ | 急がせるのは判断させないための典型的な手口 |
| 前回の顧客は2倍になった | 過去の一例は将来を何も保証しない |

## 日本の法律では「保証トーク」はどう扱われますか？

日本の[金融商品取引法](https://laws.e-gov.go.jp/law/323AC0000000025)は、登録された業者に対しても、「必ず値上がりする」といった断定的な判断を示して勧誘することや、損失を補てんする約束を原則として禁じています。つまり、正規の業者であれば「保証します」と軽々しく言えない仕組みになっています。

逆に言えば、保証を連発する相手は、ルールを守る気がないか、そもそも登録を受けていない可能性があります。金融庁も、無登録の海外業者について「トラブルが起きても追及が極めて困難」と注意を呼びかけています（[金融庁：無登録で金融商品取引業を行う者の名称等について](https://www.fsa.go.jp/ordinary/chuui/mutouroku.html)）。

## 保証トークを見抜くチェックポイントは？

次の5つのうち1つでも当てはまれば、いったん立ち止まるのが安全です。

1. **利回りの数字が先に出てくる**：商品の中身（何に投資するか）より先に「年◯％」が強調される。
2. **保証の主体があいまい**：「会社が保証」「仕組みで保証」と言うだけで、契約書に条件が書かれていない。
3. **急がせる**：「今月中」「枠が残りわずか」と判断の時間を与えない。
4. **紹介報酬がある**：知人を紹介すると報酬が出る仕組み。集めたお金で配当を払う、いわゆるポンジ・スキームの典型です。
5. **出金の話をすると話をそらす**：解約や出金の条件を聞くと答えがはっきりしない。

なお、海外積み立てプランそのものは、正規の保険会社が提供する「価格が動く」商品です。ファンドの値動きによって評価額は上下するため、正規の商品であっても高い利回りの保証はありません。IFAが「この積み立ては年9％で増えます」と言った場合も、それは保証ではなくシミュレーション上の仮定にすぎません（[シミュレーション通りに増えない理由](/blog/why-not-like-simulation)も参照）。

## 相手が本物か、どこで確認できますか？

相手の会社名・個人名・登録番号を聞き、公的な登録簿で自分で検索するのが確実です。相手から送られてきたリンクではなく、検索エンジンから当局の公式サイトを開いてください。

| 確認したいこと | 確認先 |
| --- | --- |
| 日本で登録された金融商品取引業者か | 金融庁「免許・許可・登録等を受けている業者一覧」 |
| 金融庁から警告を受けた無登録業者か | [金融庁：無登録の海外所在業者リスト](https://www.fsa.go.jp/ordinary/chuui/mutouroku/04.html) |
| 香港の証券ライセンスを持つか | [香港SFCの公的登録簿](https://apps.sfc.hk/publicregWeb) |
| 香港の保険仲介ライセンスを持つか | [香港保険業監管局（IA）の登録簿](https://ia.org.hk/en/supervision/reg_ins_intermediaries/registers_of_insurance_intermediaries.html) |

ただし、ライセンスがあることは「その商品が安全」という意味ではありません。登録の有無は最低限の確認であり、保証トークがあれば登録業者でも警戒が必要です。検索の手順は[IFAのライセンスを確認する方法](/blog/verify-ifa-license)で詳しく説明しています。

## すでに契約してしまったら、何をすればいいですか？

まず、手元の契約書類で「どの会社と契約したのか」「保証の条件は文書にあるか」を確認します。次に、その会社に自分で直接連絡し、口座が実在するか、評価額はいくらかを確かめます。

おかしいと感じたら、追加の送金は止め、やりとりの記録（メッセージ、振込明細、資料）を保存してください。相談先としては、金融庁の金融サービス利用者相談室、消費生活センター（局番なし188）、弁護士などがあります。

ご自身の契約内容を整理したい場合は、[AIチャット](/chat)で保有状況をまとめることもできます。
