株価が大きく下がり、積み立ての評価額がみるみる減っていくと、「このまま払い続けていいのか」と不安になるのは自然なことです。結論から言うと、暴落そのものは積み立てを止める理由になりません。避けたいのは、暴落のときにやりがちな3つの行動です。

## 暴落したら、積み立ては止めたほうがいいの？

相場が下がったことだけを理由に止める必要はありません。毎回同じ金額で買い続ける方法（ドルコスト平均法）では、価格が下がった月ほど多くの口数を買うことになり、平均の買値が下がるからです。

簡単な例で見てみます。前提は、毎月1万円を12か月積み立て、価格は100から50まで下がった後、100まで戻るというものです（手数料・為替は考慮なし）。

| 項目 | 結果 |
| --- | --- |
| 投資した金額の合計 | 12万円 |
| 12か月の価格の単純平均 | 75 |
| 実際の平均取得単価（1口あたりの平均の買値） | 約70.95 |
| 価格が100に戻ったときの評価額 | 約16万9,127円 |

価格が「元に戻っただけ」なのに、評価額は投資額を4割ほど上回っています。下げている間に、安い価格で多くの口数を買えたためです。くわしい計算は[暴落は「安く買えるセール」になる理由](/blog/dollar-cost-averaging-crash)で解説しています。

ただし、これは価格が戻ることを前提にした例です。戻る時期や水準は誰にも約束できません。大切なのは、「下がったときに口数を多く買う」という仕組みを知ったうえで判断することです。

## 長期投資家がやってはいけない3つの行動とは？

暴落時に損を大きくしやすい行動は、次の3つです。

| 行動 | なぜ問題になりやすいか |
| --- | --- |
| 1. 狼狽売り（ろうばいうり） | 下がった後に売ると、損失が確定し、その後の回復に乗れない |
| 2. 相場を理由にした積み立て停止 | 一番安く買える時期に買うのをやめることになる |
| 3. スイッチの連発 | 下がった後に安全資産へ移し、上がった後に戻ると「安く売って高く買う」形になりやすい |

### 1. 狼狽売り

狼狽売りとは、不安に駆られて慌てて売ることです。評価額の下落は、売るまでは「途中経過」ですが、売った時点で損失は確定します。海外の積み立てプランでは、解約の時期によっては解約控除（早く解約したときに差し引かれる費用）もかかるため、損失がさらに大きくなることがあります。

### 2. 相場を理由にした停止

積み立てを止めると、価格が安い時期の買い付けがなくなります。上の例で言えば、価格が50前後の月に買えたはずの口数を手放すことになります。また、停止中も管理費などの手数料は差し引かれ続けるのが一般的です。

### 3. スイッチの連発

スイッチとは、積み立ての契約の中でファンドを入れ替えることです。値動きを見てスイッチを繰り返すと、売買の時期を当て続ける必要があり、現実にはとても難しい作業です。スイッチの基本は[ファンドの入れ替え方法](/blog/how-to-switch-funds)をご覧ください。

## では、どんなときに積み立ての見直しを考えるの？

見直しのきっかけは、相場ではなく「自分側の事情」です。たとえば次のような場合です。

- 収入が減り、生活費や数か月分の予備資金が足りなくなった
- 近いうちに大きな支出があり、この積み立てを取り崩す可能性が高い
- 契約内容や手数料を理解しないまま払い続けていると気づいた

こうした場合でも、停止・減額・解約はそれぞれ条件や費用が違います。特に初期口座（イニシャルユニット：最初の期間に払った分。手数料が重い）の期間中は、解約控除などの費用が大きくなりやすい点に注意してください。

## 暴落の不安とどう付き合えばいいの？

評価額を見る頻度を決めておくことが、もっとも手軽な対策です。毎日見ても判断が良くなるとは限らず、不安だけが大きくなりがちです。月に1回、3か月に1回など、ルールを先に決めておくと振り回されにくくなります。

また、自分の積み立てが何にどれだけ投資しているのかを知っておくと、下げの大きさを冷静に受け止めやすくなります。保有内容を整理したい方は[AIチャット](/chat)もご利用ください。

## 暴落の前に、決めておけることは？

暴落のさなかに冷静な判断をするのは、誰にとっても難しいものです。そのため、相場が落ち着いているうちに「自分のルール」を決めておくことが、もっとも効果的な備えになります。

| 決めておくこと | 例 |
| --- | --- |
| 生活資金の範囲 | 生活費の数か月分は、積み立てとは別の預金で持っておく |
| 評価額を見る頻度 | 月1回、または3か月に1回だけ確認する |
| 配分を見直す時期 | 年1回など、日付で決めておく（[リバランスの考え方](/blog/rebalancing)） |
| 停止や減額を考える条件 | 「収入が一定以上減ったとき」など、相場ではなく家計の条件で決める |
| 契約の条件 | 停止・減額ができる時期と手数料を、契約条件書で確認しておく |

特に最後の項目は見落とされがちです。たとえばRL360の積み立て商品「クォンタム」では、払い込みの一時停止は初期口座期間の後で、評価額が一定額を上回っている場合に限られ、停止中は毎月の固定手数料が上がると資料に記載されています。いざというときに「止められると思っていたのに止められなかった」とならないよう、条件は事前に知っておきましょう。

ルールを紙やメモに書いておくと、暴落のときに見返すことができます。そのときの気分ではなく、落ち着いていたときの自分の判断に従えるようにしておくことが、長期投資を続けるための現実的な工夫です。

## まとめ

暴落そのものは、積み立てを止める理由にはなりません。一定額の積み立ては、安い時期に多く買う仕組みだからです。避けたいのは、狼狽売り・相場を理由にした停止・スイッチの連発の3つです。続けるかどうかは、相場ではなく、家計と契約条件で判断するのが基本です。個別の状況について相談したい方は、[お問い合わせ](/contact)から提携先のアドバイザーをご紹介できます。
