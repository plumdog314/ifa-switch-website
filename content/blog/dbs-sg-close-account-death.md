「日本に戻ったので、シンガポールのDBSの口座を閉じたい」「海外に口座を持っていた家族が亡くなった」。こうした場面での手続きを整理します。結論から言うと、DBSとPOSBの多くの普通預金・当座預金は、オンラインバンキングの「digibank Online」から解約できます。名義人が亡くなった場合は、シンガポールの裁判所の書類をそろえて手続きします。

この記事では、DBS銀行（DBS Bank Ltd）の公式のヘルプページをもとに、本記事の確認時点（2026年11月）の内容を整理します。POSBはDBSのブランドの一つで、解約と相続の手続きは同じページで案内されています。口座を閉じるかどうかを勧めるものではありません。

## 日本からオンラインで解約できるの？

個人名義の口座は、digibank Onlineから解約できます。[解約の案内ページ](https://www.dbs.com.sg/personal/support/bank-account-closure.html)に書かれている手順は次のとおりです。

1. digibank OnlineにUser IDとPINでログインし、認証を済ませる
2. 「Deposits」から解約したい口座を選ぶ
3. 「Manage」の「Close this account」で「Close」を押す
4. 残高の移し先の口座を選び、内容を確認して「Confirm」を押す

対象は、DBSとPOSBの普通預金（Savings Account）、DBS Multiplier、My Account、DBS eMulti-Currency Autosaveなどの当座預金です。共同名義のうち、どちらか一人の署名で取引できる口座（Joint Alternate）も含まれます。同じページには、郵送での解約の申し込みは受け付けていないと書かれています。また解約は取り消せません。ログインできない方は[DBS銀行（シンガポール）にログインできないときは？](/blog/dbs-sg-dormant-login)を先にご覧ください。

## オンラインで解約できない口座は？

次の口座は、DBSやPOSBの支店での手続きになると案内されています。

| オンラインで解約できない口座 | 補足 |
| --- | --- |
| DBSで持つ最後の1口座 | 支店での手続き |
| 両方の署名が必要な共同名義の口座（Joint-All） | 名義人2人とも支店に行く必要がある |
| 亡くなった方の口座・遺産の口座 | 次の章を参照 |
| 定期預金、小切手帳のある口座、投資口座など | 支店での手続き |
| PayLah!につないでいる口座 | 先につなぐ口座を変える |

日本に住む方にとって大切なのは、DBSで最後の1口座はオンラインで閉じられない点です。日本から行う別の方法は、公開の案内では確認できませんでした。海外からの電話窓口（DBSは(65) 6327 2265）は、DBSの[問い合わせページ](https://www.dbs.com.sg/personal/contact-us)に載っています。

## 解約の前に、残高はどう動かせばいいの？

解約の画面では、残高をDBSのほかの口座に移せます。日本の銀行など外に移したい場合は、解約を申し込む前に、digibankの海外送金などで送っておくよう案内されています。日本への送金の方法と手数料は[DBS銀行（シンガポール）から日本へ送金するには？](/blog/dbs-sg-transfer-to-japan)で整理しています。

ほかにも、解約のページには次の注意があります。

- 残高がマイナスかS$1未満なら、S$1以上を入れてから外に移す
- 処理中の取引が残っている場合は、数日待って残高を0にする
- 口座につないだATMカード・デビットカードやGIRO（口座振替）は、解約と同時に止まる
- 解約時にまだ記帳されていない取引は、あとから明細で確認できない

[預金の手数料表](https://www.dbs.com.sg/iwov-resources/pdf/deposits/DBS_deposit_guide.pdf)には、開いてから6か月以内の解約で手数料S$30がかかる項目もあります。

## 名義人が亡くなったら、家族は何をするの？

DBSは、3つの段階で手続きを案内しています。[亡くなった方の口座の案内ページ](https://www.dbs.com.sg/personal/support/bank-account-closure-deceased-account.html)の内容です。

1. 遺言書を探す
2. 裁判所に書類を申請する（遺言があれば検認（Grant of Probate）、なければ遺産管理の書類（Letters of Administration））
3. DBSに連絡し、支店で口座の解約とお金の受け取りを行う

検認とは、裁判所が遺言の有効性を確認し、遺言の実行役（遺言執行者）を認める手続きです。DBSは、書類の申請には事情によって2〜6か月かかることがあり、弁護士への依頼も考えられると書いています。

申請先は、遺産の額で変わります。S$500万を超えると高等裁判所の家事部（Family Division of the High Court）、S$500万未満は家庭裁判所（Family Courts）です。遺産の総額がS$50,000未満なら、公的な財産管理の機関（Public Trustee's Office）が手伝う場合があります。

共同名義の口座は、名義人の一人が亡くなると、入出金や口座振替が止まります。残った名義人が支店で指示を出すまで、この状態が続きます。

## 家族が日本にいる場合は、どうなるの？

遺産の代理人がシンガポールに行けない場合は、書面での依頼を郵送できます。同じページによると、必要な書類は次のとおりです。

| 書類 | 条件 |
| --- | --- |
| 死亡証明書の写し | 公証を受けたもの |
| 検認または遺産管理の書類の写し | 公証を受けたもの。海外で出たものはシンガポールの裁判所で再承認（reseal）したもの |
| 結婚証明書の写し | 該当する場合、公証を受けたもの |
| 遺言執行者・遺産管理人のパスポートなどの写し | 公証を受けたもの |
| 口座解約の書類と電信送金の依頼書 | 原本に手書きで署名し、公証を受けたもの |

公証は、シンガポールの弁護士（advocate and solicitor）か公証人（notary public）が行うものとされ、単なるコピーは受け付けられません。書類はすべて英語で、英語以外は公的な翻訳者の英訳が必要です。

日本の裁判所などで出た書類だけでは足りず、シンガポールの裁判所が出した書類か、海外の書類をシンガポールの裁判所で再承認したものが必要です。DBSは、シンガポールでの申請についてシンガポールの弁護士に助言を求めることも考えられる、と書いています。送り先の住所は、案内ページに載っている部署あてです。

海外積み立ての契約者が亡くなった場合の流れは[契約者が亡くなったら海外積み立てはどうなる？](/blog/if-policyholder-dies)で解説しています。

## まとめ

DBS銀行（シンガポール）の個人の普通預金・当座預金は、digibank Onlineから解約でき、郵送での申し込みは受け付けていません。本記事の確認時点（2026年11月）では、DBSで最後の1口座や定期預金などは支店での手続きです。名義人が亡くなった場合は、シンガポールの裁判所の書類と、公証と英訳を済ませた書類が必要で、家族が日本にいる場合は郵送での手続きが案内されています。
