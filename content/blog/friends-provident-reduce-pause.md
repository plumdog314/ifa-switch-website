「フレンズプロビデントの積み立てを、しばらく止めたい」「金額を下げられないか」。そう考えたとき、最初に知りたいのは何ができて、何に気をつけるかです。結論から言うと、フレンズプロビデント・インターナショナル（FPI）の積み立て型プランには、一時停止や減額の仕組みがあります。ただし、最低払込額、停止できる期間、停止中も続く手数料などの条件があり、条件はプランと契約時期によって違います。

この記事では、FPIの公式資料に沿って仕組みと手続きを整理します。減額や停止をするかどうかを勧めるものではありません。会社の経緯は[フレンズプロビデント（FPI）ってどんな会社？](/blog/what-is-friends-provident)をご覧ください。

## どんな選択肢が用意されているの？

FPIの案内資料には、一時停止、減額、払込の完全停止、再開などが並んでいます。資料「[Your premium options](https://www.fpinternational.com/documents/xim-ret-opt-fly.pdf)」（XIM_RET_OPT_FLY 04.20）に書かれている内容を表にまとめます。

| 選択肢 | 公式資料での説明 |
| --- | --- |
| プレミアムホリデー（一時停止） | 決まった期間、払込を休む。再開はいつでもできる |
| 減額 | 払込額を下げる。プランの最低払込額は守る必要がある |
| ペイドアップ（払込の完全停止） | 期限を決めずに払込を止める。再開はいつでもできるが、自動で再開する仕組みはプランによってない |
| 再開 | いつでも再開でき、元の額より低い額で始めることもできる |
| 引き出し | 積立口座（アキュムレーションユニット）から、手数料なしで引き出せる |

初期口座と積立口座の違いは[初期口座と積立口座の違い](/blog/initial-vs-accumulation-units)で解説しています。

## 減額や停止には、どんな条件があるの？

条件は約款（Policy conditions）で決まります。ここでは、FPIが公開している「[プレミア・アドバンス（Premier Advance）の約款](https://advisers.fpinternational.com/documents/pai2.pdf)」（PAI2、2012年11月版）を例に紹介します。ほかのプランや別の時期の契約では内容が違うことがあります。

| 項目 | プレミア・アドバンスの約款の内容 |
| --- | --- |
| 減額 | 最低払込額は1契約あたり月300米ドル（四半期900、半年1,800、年3,600米ドル）。初期期間中は減額できない |
| 一時停止 | 初期期間が終わった後、最長12か月。書面で知らせる必要がある |
| 停止中の手数料 | 所定の手数料は差し引かれ続ける |
| 停止後に再開しない場合 | 停止期間の終了から1か月以内に再開しないと、ペイドアップの扱いになる |
| 最低契約価値 | 初期期間の後は2,000米ドル以上を保つ必要があり、下回ると解約の扱いになる |

初期期間とは、契約の始まりから契約明細（Policy schedule）に書かれた期間のことで、この間の払込で初期口座が作られます。FPIの別の案内資料では、プレミアの例として初期期間を18か月としています（[Restarting premiums](https://www.fpinternational.com/documents/xim-pup-reinst-fly01.pdf)）。ご自身の期間は契約明細で確認してください。

## 初期期間中に払込が止まると、どうなるの？

プレミア・アドバンスの約款では、初期期間中の払込が足りないと、契約が終わって解約の扱いになるとされています。払込が期日から90日以内にない場合はペイドアップの扱いになり、それが初期期間中であれば、解約控除を差し引いて解約されると書かれています。

また、約款には、契約から1年が過ぎ、12か月分以上を払い込むまでは、初期口座に解約返戻金がつかないとも書かれています。解約返戻金の考え方は[フレンズプロビデントの解約返戻金はいくら？](/blog/friends-surrender-value)で整理しています。

## 減額や停止で、別の手数料がかかることはあるの？

プランによってはあります。プレミア・アドバンスの約款では、最初の払込額に上乗せの配分（エンハンスト初期ユニット）があった契約について、契約5年目より前に一定の状況になると、上乗せ分を取り戻す手数料（enhanced initial unit recovery charge）がかかると定めています。

| 手数料がかかる主な場面（契約5年目より前） |
| --- |
| 払込の停止が、連続または通算で12か月を超えた |
| 元の額より少ない払込が、連続または通算で12か月を超えた |
| 減額と停止を合わせて、12か月を超えた |
| ペイドアップになった |

上乗せの配分があったかどうかは、契約明細で確認できます。手数料の計算式は約款に書かれていますが、実際の金額はFPIに確認するのが確実です。

## 停止を続けると、将来の金額はどう変わるの？

FPIの資料では、払込を止めた期間が長いほど、当初の目標額から離れていくと説明されています。資料「Restarting premiums」でも、早い時期にペイドアップにすると、最後まで払い込んだ場合と比べて最終的な金額が大きく減る例が示されています（仮定にもとづく試算で、将来を約束するものではありません）。

停止した後に再開する場合の考え方は[停止していた積み立てを再開したら「まとめて払え」と言われた](/blog/lump-payment-after-pause)も参考になります。払込が長く止まった契約の再開では、FPIの「[Application to restart a policy](https://www.fpinternational.com/documents/FPILUW01-Application-to-restart-a-policy.pdf)」という健康状態の申告書を求められることがあります。この書式には、払込が止まった理由と最初の未払い日を書く欄があります。

## 申し込みはどこから、どうやって行うの？

FPI Portal（オンラインの契約者ページ）か、カスタマーサービスへの連絡で申し込みます。FPIの案内「[Contacting FPI](https://www.fpinternational.com/documents/corp003-contacting-fpi.pdf)」には、Portalで払込の一時停止（premium break）と再開を申し込めると書かれています。

メールで問い合わせる場合、同じ資料では、払込に関する件は件名に「P#R1」と証券番号を入れるよう案内されています。宛先はcustomerservices@fpiom.com、電話はマン島の+44 1624 821212です。プレミア・アドバンスの約款では、一時停止は書面で知らせることが条件です。払込方法の変更などは[フレンズプロビデントの住所・カード変更の手続き](/blog/friends-provident-change-address-card)で解説しています。

## まとめ

フレンズプロビデントの積み立て型プランには、一時停止、減額、ペイドアップ、再開の仕組みがあります。プレミア・アドバンスの約款では、減額は月300米ドルまで、一時停止は初期期間の後に最長12か月で、停止中も手数料はかかります。条件はプランと契約時期で違うため、本記事の確認時点（2026年11月）の資料をもとに、ご自身の約款と契約明細で確かめてください。減額や停止の一般的な考え方は[積み立てを減額したいときの手続きとデメリット](/blog/reduce-contributions)と[積み立てを一時停止したいときの手続きと注意点](/blog/pause-contributions)で解説しています。
