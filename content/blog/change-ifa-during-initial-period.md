「今のIFA（保険会社の商品を販売し、契約の窓口になる独立系の担当者）とは連絡が取りにくい。でも初期口座期間（最初の期間に払った分に手数料が重くかかる期間）が終わるまでは変えられないのでは」。契約して1〜2年の方から、こうした相談がよくあります。結論から言うと、初期口座期間中でもIFAの変更は手続きできるのが一般的です。ただし、変更しても初期口座の条件は変わらないこと、新しいIFAの報酬の仕組みを確認しておくことなど、いくつかの注意点があります。

## 初期口座期間中でもIFAは変えられるの？

一般的には変えられます。IFAの変更は、保険会社に登録されている担当代理店を替える手続きで、契約者本人の依頼によって行います。初期口座期間中かどうかで、手続き自体ができなくなるわけではないのが通常です。

ただし、保険会社や商品、契約の地域によっては、受け付けの条件や必要書類が違うことがあります。「今は変えられない」と言われた場合は、その理由を確認したうえで、契約者本人から保険会社に直接問い合わせてみてください。

初期口座とは、契約の最初の一定期間に払ったお金が入る口座で、契約期間を通じて費用がかかる設計になっていることが多いものです。

## IFAを変えると、初期口座の期間や費用は変わる？

変わりません。初期口座の期間、初期口座にかかる費用、途中解約のときの解約控除（早く解約したときに差し引かれる費用）は、契約の条件として決まっており、担当のIFAが誰であっても同じです。

| 項目 | 初期口座期間中にIFAを変えた場合 |
| --- | --- |
| 初期口座の期間 | 変わらない（終わったり延びたりしない） |
| 初期口座の費用 | 変わらない |
| 解約控除 | 変わらない |
| 毎月の積立額 | 変わらない（変更する場合は別の手続き） |
| 運用中のファンド | 変わらない（変更する場合は別の手続き） |
| 相談・手続きの窓口 | 新しいIFAになる |

「IFAを変えれば費用が下がる」「初期口座期間が最初からやり直しになる」といったことは、通常はありません。逆に、変更によって不利な条件が加わることも、一般的にはありません。

## 初期口座期間中の変更で、気をつけることは？

主に3つあります。

**1. 新しいIFAの報酬の仕組み**

IFAの報酬は、保険会社からの手数料や、契約者が払う助言の手数料（アドバイザリーフィー）などで成り立っています。初期口座期間中に担当が変わると、新しいIFAが保険会社から受け取れる報酬がない、または少ないことがあります。その場合、新しいIFAが別にサポートの費用を求めることもあります。費用の有無と金額、サポートの範囲を、変更の前に書面で確認しておきましょう。報酬の仕組みは[アドバイザリーフィー1％は妥当？IFAの報酬の仕組み](/blog/advisory-fee)で解説しています。

**2. 旧IFAとの関係**

旧IFAにとって、初期口座期間中の契約は、まだ報酬の計算が終わっていない契約であることがあります。そのため、変更を引き止められたり、強い言葉で説明されたりすることもあります。とはいえ、IFAの変更は契約者が決めることです。手続きは、契約者本人が署名した変更依頼書を保険会社に出すことで進められるのが一般的です。

**3. 「解約して入り直す」提案ではないか**

「IFAを変えるなら、今の契約を解約して新しいプランに入り直しましょう」という提案には注意が必要です。初期口座期間中に解約すると解約控除が大きく差し引かれ、新しいプランでもまた初期の費用がかかります。通常のIFA変更では、解約は必要ありません。

## 変更の手続きはどう進むの？

一般的な流れは次のとおりです。

| 手順 | 内容 |
| --- | --- |
| 1. 新しいIFAを選ぶ | 免許と、その保険会社への代理店登録を確認する |
| 2. 変更依頼書を用意する | 保険会社の様式、または新しいIFAが用意する書類に契約者が署名する |
| 3. 本人確認書類を添える | パスポートの写しや住所証明を求められることがある |
| 4. 保険会社が手続き | 受け付け後、担当代理店の記録が変更される |
| 5. 変更の確認 | 保険会社からの通知や、オンライン口座で担当が変わったことを確認する |

詳しい手順は[IFAを変更（移管）する手続きと流れ](/blog/how-to-change-ifa)をご覧ください。違約金についての疑問は[IFAを変えると違約金がかかる？契約は続けられる？](/blog/ifa-transfer-penalty)でまとめています。

## 初期口座期間中にIFAを変えるかどうか、どう考える？

判断の軸は「今のIFAから必要なサポートを受けられているか」です。初期口座期間中かどうかは、変えられるかどうかを決める大きな要素にはなりにくいと言えます。

たとえば、次のような状態が続いているなら、変更を検討する理由になりえます。

- 問い合わせへの返事が来ない、または非常に遅い
- ファンドの閉鎖や統合などの通知について説明がない
- 手数料や契約の条件について、質問しても明確な説明がない
- 新しい契約や増額ばかりを勧められる

反対に、連絡がつき、質問にも丁寧に答えてもらえているなら、初期口座期間中に急いで変える理由は小さいかもしれません。大切なのは、時期ではなくサポートの中身で考えることです。

## まとめ

初期口座期間中でも、IFAの変更は手続きできるのが一般的です。変更しても、初期口座の期間や費用、解約控除といった契約の条件は変わりません。気をつけたいのは、新しいIFAの報酬とサポートの範囲、旧IFAとのやり取り、そして「解約して入り直す」提案でないかの3点です。
