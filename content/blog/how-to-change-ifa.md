「担当者と連絡が取れない」「説明に納得できない」。そうした理由でIFAを変えたいと思っても、「変えたら契約がどうなるのか」が心配で動けない方は多くいます。結論から言うと、IFAの変更は、新しいIFAを決めて、保険会社所定の書類に署名して提出するのが基本の流れです。プランを解約する必要はありません。

## IFAを変更しても、プランはそのままなの？

そのままです。契約は保険会社との間で結ばれており、IFAは窓口となる仲介者です。IFAを変更しても、次のものは引き継がれます。

| 引き継がれるもの | 変わるもの |
| --- | --- |
| 契約番号、積立額、契約期間 | 登録されているアドバイザー（代理店） |
| 保有ファンド、評価額 | 問い合わせや手続きの窓口 |
| 初期口座の状況、解約控除の条件 | アドバイザー報酬の支払い先（設定がある場合） |

つまり、IFAの変更は「契約のやり直し」ではなく、「担当窓口の付け替え」です。この点を理解しておくと、手続きへの不安がかなり小さくなります。

## 変更の手続きは、どんな流れで進むの？

一般的な流れは次のとおりです。

| 手順 | 内容 |
| --- | --- |
| 1. 新しいIFAを決める | ご自身の保険会社と取引関係（代理店契約）がある会社かを確認する |
| 2. 書類を準備する | 保険会社所定のアドバイザー任命・変更の書類を入手する |
| 3. 署名して提出する | 契約者（共同契約なら全員）が署名し、新しいIFA経由または直接保険会社へ提出する |
| 4. 本人確認に対応する | 追加で本人確認書類や住所証明を求められた場合は提出する |
| 5. 完了を確認する | 保険会社から登録変更の確認を受け取る |

保険会社によって書類の名前は違います。たとえばRL360には、契約者が新しいアドバイザーを任命する[アドバイザー任命の書類](https://www.rl360.com/generic/downloads/rl267-financial-adviser-appointment.pdf)があり、書類はRL360の[書類ダウンロードページ](https://rl360.com/row/downloads/forms.htm)で公開されています。

## 必要な書類は何？

主に次のものが必要になります。

- 保険会社所定のアドバイザー任命・変更の書類（契約者の署名入り）
- 契約番号が分かるもの（評価書や証券）
- 本人確認書類（パスポートなど）と住所証明（求められた場合）

署名は、保険会社に登録されている署名と同じものを使います。署名が違うと、本人確認のために手続きが止まることがあります。本人確認書類の出し方は[本人確認・住所証明の提出を求められたら](/blog/kyc-documents)で解説しています。

## 期間と費用はどれくらい？

期間は、保険会社や書類の状況によって異なります。書類に不備がなくても登録の変更までには一定の日数がかかり、不備や追加の本人確認があるとさらに長くなります。提出したら受付の確認を必ずとり、完了までの目安を保険会社に尋ねておきましょう。

費用については、変更手続きそのものに保険会社の手数料がかかるかどうかは、会社と契約によって異なります。また、次の点も確認が必要です。

- **前のIFAへのアドバイザー報酬**：評価額から報酬が差し引かれる設定がある場合、それを止めるのか、新しいIFAに移すのか
- **新しいIFAの報酬**：新しいIFAが何に対して、いくらの報酬を受け取るのか
- **運用の権限**：前のIFAにファンドのスイッチの権限を渡している場合、その解除

違約金がかかるのかという疑問は[IFAを変えると違約金がかかる？](/blog/ifa-transfer-penalty)で、初期口座期間中の変更は[初期口座期間中でもIFAは変更できる？](/blog/change-ifa-during-initial-period)で解説しています。

## 変更の前に、気をつけたいことは？

新しいIFAを選ぶときは、免許を持っているか、報酬の仕組みを書面で説明してくれるかを確認しましょう。また、「IFAを変えるついでに解約して新しいプランに入り直しましょう」という提案には注意が必要です。新しい契約には新たな初期口座期間と手数料が生じます。IFAの変更とプランの変更は、別の問題として考えることが大切です。

## 新しいIFAとの間で、書面にしておきたいことは？

IFAを変更した後に同じ不満を繰り返さないためには、新しいIFAとの間で、最初に次の点を書面やメールで確認しておくことが大切です。

| 確認すること | 内容の例 |
| --- | --- |
| 提供してくれるサービス | 年1回の見直し、手続きの代行、問い合わせへの対応など |
| 報酬 | 何に対して、いくら（何％）か。いつから差し引かれるか |
| 連絡の方法と頻度 | メールか電話か、返事の目安、定期的な連絡の有無 |
| 運用の権限 | ファンドのスイッチを、契約者の同意なしに行えるかどうか |
| 担当者が辞めた場合 | 会社として誰が引き継ぐのか |

特に報酬は、口頭の説明だけで済ませず、どの書類に記載されるのかまで確認しておきましょう。保険会社所定の書類に報酬の割合を書く欄がある場合は、その内容をよく読んでから署名することが大切です。

また、新しいIFAが変更の直後に、解約や新規契約、増額を強く勧めてくる場合は、一度立ち止まって考える時間をとりましょう。IFAの変更は、今のプランを落ち着いて点検し直すためのものです。点検の結果どうするかは、説明を受けたうえで契約者自身が決めることです。

## まとめ

IFAの変更は、新しいIFAを決め、保険会社所定の書類に契約者が署名して提出するのが基本です。契約は保険会社との間にあるため、プランを解約する必要はなく、中身もそのまま引き継がれます。報酬の扱いや運用の権限も合わせて確認しましょう。IFAスイッチでは、[お問い合わせ](/contact)から提携先のライセンスを持つアドバイザーをご紹介できます。
