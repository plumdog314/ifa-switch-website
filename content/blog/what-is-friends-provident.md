「フレンズプロビデントの積み立てを続けているけれど、日本では販売をやめたと聞いた。自分の契約は大丈夫なのか」。そんな不安の声をよく聞きます。結論から言うと、フレンズプロビデント・インターナショナル（FPI）はマン島に本拠を置く生命保険会社で、日本居住者からの新規契約の受付は2012年ごろに停止されましたが、既存の契約は条件に従って続いています。ただし、変更できることに制限がある点は知っておく必要があります。

## フレンズプロビデント・インターナショナルはどんな会社ですか？

フレンズプロビデント・インターナショナル（Friends Provident International、略称FPI）は、マン島に本拠を置く生命保険会社で、国際的な貯蓄型・投資型の保険商品を扱ってきました。

英国の老舗の生命保険会社フレンズプロビデントのグループから生まれた国際部門で、マン島の金融監督当局（IOMFSA）の監督を受けています。アジアでは香港やシンガポール、中東ではドバイに拠点を持ってきました。マン島の位置づけや規制については[マン島の記事](/blog/isle-of-man)で解説しています。

## 親会社はどう変わってきたのですか？

FPIの親会社は、英国の大手保険グループのアビバを経て、RL360と同じグループに移りました。

| 時期 | 出来事 |
| --- | --- |
| 2017年7月 | アビバが、FPIをRL360の持株会社（インターナショナル・ファイナンシャル・グループの子会社）に3億4,000万ポンドで売却すると発表 |
| 2020年7月 | 条件を見直したうえで売却が完了。アビバは少数株主として一部の株式を保有 |

出典：[Aviva（2017年7月）](https://www.aviva.com/newsroom/news-releases/2017/07/aviva-to-sell-fpil-17796/)、[Aviva（2020年7月）](https://aviva.com/newsroom/news-releases/2020/07/aviva-completes-the-sale-of-fpil)

報道によると、見直し後の条件では、アビバがFPIの株式の76%を売却する形となりました。現在、FPIとRL360は別々の保険会社ですが、同じグループに属しています。RL360については[RL360の記事](/blog/what-is-rl360)をご覧ください。

## 日本での販売はいつ、なぜ停止されたのですか？

FPIは2012年ごろに日本居住者からの新規契約の受付をやめ、2013年には既存契約の増額や追加払込の受付も停止しました。

業界紙International Adviserの2013年7月の報道によると、FPIは、前年に日本居住者からの新規契約の受付をやめた決定に続き、日本居住者の既存契約について、払込額の増額と追加払込（トップアップ）の受付を2013年7月31日で終了すると、アドバイザーに通知しました（[International Adviser](https://www.international-adviser.com/?p=7129)）。FPIは、こうした取引の依頼がごく少なかったと説明していたと報じられています。

背景として、日本では、日本に支店等を設けていない外国保険会社が日本居住者と保険契約を結ぶことが、[保険業法第186条](https://www.fsa.go.jp/news/r6/hoken/20241017/20241017.html)で原則として禁止されています。FPIが停止の理由をどこまで公式に説明したかは確認できませんでしたが、こうした日本の規制環境は、海外の保険会社が日本居住者との取引を考えるうえで避けて通れない要素です。

その後もFPIは事業の見直しを続け、2015年には香港・シンガポール・ドバイなど一部の地域以外からの新規契約の受付をやめる方針を発表したと報じられています。

## 既存の契約者にはどんな影響がありますか？

新規の受付停止は、既存の契約を無効にするものではありません。契約は契約条件に従って続きます。

| 項目 | 影響の考え方 |
| --- | --- |
| 契約の継続 | 契約条件に従って続く |
| 通常の払込 | 契約どおりの払込は続けられるのが一般的 |
| 増額・追加払込 | 日本居住者は2013年7月末で受付終了と報じられている |
| ファンドの変更・解約・引き出し | 契約条件に従って手続きできるのが一般的 |
| 補償制度 | マン島の保険会社として、契約者補償制度の対象となりうる |

※具体的に何ができるかは契約の種類によって異なるため、保険会社に確認してください。

注意したいのは、販売停止によって、日本人の契約者を担当していたIFA（保険会社の商品を販売し、契約の窓口になる独立系の担当者）が事業を縮小したり、連絡が取れなくなったりする場合があることです。担当者がいなくても、契約者本人が保険会社に直接連絡して、明細の取り寄せや手続きを行えるのが一般的です。解約返戻金（解約したときに戻ってくるお金）の確認方法は[フレンズプロビデントの解約返戻金の記事](/blog/friends-surrender-value)、契約書類の読み方は[証券書類の記事](/blog/friends-policy-document)で解説しています。

## 契約者は今、何を確認すればいいですか？

まずは、次の点を手元の書類や保険会社の画面で確認しましょう。

1. 証券番号と契約の種類
2. 払込の状況（毎月の額、未払いがないか）
3. 現在の評価額と解約返戻金
4. 保有しているファンドと、その状況（取引停止などがないか）
5. 担当IFAの連絡先と、連絡が取れるかどうか
