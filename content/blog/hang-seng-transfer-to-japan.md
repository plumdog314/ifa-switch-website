「ハンセン銀行（恒生銀行）の口座にあるお金を、日本の自分の口座に移したい」。海外積み立ての解約金や満期金を香港の口座で受け取った方から、よく聞く相談です。結論から言うと、ハンセン銀行から日本への送金は、オンラインのPersonal e-Banking（インターネットバンキング）を使うと銀行の手数料がHK$65です。アプリや支店でも送れますが、手数料が変わります。

この記事では、ハンセン銀行の[料金表（2026年7月1日適用）](https://www.hangseng.com/content/dam/wpb/hase/config/bde/pws/personal/servicecharges/pdfs/tariff_personal_e.pdf)と[ウェブサイトでの海外送金のページ](https://www.hangseng.com/en-hk/personal/banking/overseas-transfer-website/)をもとに、本記事の確認時点（2026年11月）の内容を整理します。送金するかどうかを勧めるものではありません。

## 日本に送る方法と、手数料はいくら？

送り方は、Personal e-Banking、アプリのGlobal Money+、支店などの3つです。料金表では、日本への送金の手数料は次のとおりです。

| 送り方 | 手数料 |
| --- | --- |
| Personal e-Banking（ウェブサイト） | HK$65 |
| アプリのGlobal Money+ | HK$160 |
| 支店・電話バンキングなど（香港ドルか円で送る） | HK$230 |
| 支店・電話バンキングなど（米ドルなどほかの通貨で送る） | HK$270 |

Personal e-Bankingと支店などの手数料には、中継銀行（途中で送金を取り次ぐ銀行）の手数料は含まれていません。Global Money+の手数料は、料金表では中継銀行の手数料も含むとされています。ただし、受け取る側や中継の銀行が受取人から別に手数料を引く場合があると、Global Money+のページに書かれています。

[Global Money+のページ](https://www.hangseng.com/en-hk/personal/banking/overseas-transfer/)では、カナダやイギリスなど50以上の指定の国・地域に現地通貨で送ると手数料無料と説明されています。ただし、日本は指定の国に入っておらず、同じページに日本向けの手数料はHK$160と例示されています。

Prestige PrivateとPrestige Bankingには送金手数料の優遇がありますが、料金表で免除とされているのは中国本土やマカオ向けなどです。日本向けが免除になるとは書かれていません。

## 中継銀行の手数料は、どうなるの？

手数料の負担のしかたを、送るときに選べます。選び方によって、中継銀行の手数料がどこから引かれるかが変わります。

ハンセン銀行の[個人口座の取り扱いの説明資料](https://www.hangseng.com/content/dam/hase/rwd/personal/pdfs/Descriptive-information-of-Personal-Account-Operations.pdf)には、次の3つが載っています。

- OUR：送る人がすべての手数料を払う
- BEN：受け取る人がすべての手数料を払う
- SHA：送る人がハンセン銀行の手数料、受け取る人がほかの銀行の手数料を払う

料金表には、送る人が中継銀行の手数料も払う場合（OUR）の目安が載っています。日本向けは次のとおりです。

| 送る通貨 | 条件 | 中継銀行の手数料 |
| --- | --- | --- |
| 円 | 受け取りが指定の銀行で、金額が250万円以下 | HK$200 |
| 円 | それ以外の銀行、または250万円を超える | 最低HK$350 |
| 米ドル | 米国以外の国へ | US$35 |

指定の銀行とは、三菱UFJ銀行、みずほ銀行、三井住友銀行です（料金表の表記はBank of Tokyo-Mitsubishi UFJなど）。料金表には、受け取り側や中継の銀行がさらに手数料を引く場合があり、受取人が全額を受け取れないこともあると書かれています。日本の銀行での受け取り手数料は、受け取る銀行に確認してください。

## 送金に必要な情報は？

日本の受け取り口座の情報と、自分の住所の登録が必要です。海外送金のページでは、次の情報を求めています。

- 受け取る銀行のSWIFTコード（銀行を特定する8〜11文字の記号）
- 受取人の口座番号、フルネーム、住所（市区町村まで）
- 送金の目的

同じページには、受取人と自分の住所の両方に「市区町村」を入れないと送金できないと書かれています。銀行に登録した住所の市区町村が空欄の場合は、先に更新が必要です。

## 1日にいくらまで送れるの？

オンラインでは、中国本土・海外向けの1日の上限が最大HK$1,500,000です。初めて海外に送る前に、この上限を自分で設定する必要があります。

[送金先と上限の管理のページ](https://www.hangseng.com/en-hk/personal/banking/manage-payees-and-limits/)と海外送金のページによると、上限は次のように決まっています。

| 上限の種類 | 金額 |
| --- | --- |
| 中国本土・海外向けの1日の上限 | 最大HK$1,500,000（最初の設定はHK$0） |
| 登録済みの送金先への1日の上限 | 最大HK$1,500,000（新しく登録した送金先は最初の設定がHK$50,000） |
| 未登録の送金先への1日の上限 | 最大HK$400,000（最初の設定はHK$0） |
| 支店 | 上限なし |

実際に送れる額は、これらのうち一番低い上限で決まります。上限の変更や送金先の登録をオンラインで行うには、Mobile Security Key（アプリの中の本人確認の機能）と、銀行に登録した有効な携帯番号が必要です。ログインに困っている場合は[ハンセン銀行の口座が休眠になったら？](/blog/hang-seng-dormant-login)を参考にしてください。

## 送った後に、変更や問い合わせはできる？

できますが、送金がすでに送り出された後は手数料がかかります。海外送金のページでは、送り出す前の変更や取り消しは無料です。送り出した後は、手数料HK$200と電信料（送金の通信にかかる費用）HK$100に、ほかの銀行の手数料が加わります。

届かないときの調査（電信照会）は、1件につき最低HK$250です。問い合わせは送金専用の窓口（852）2123 1088か支店で受け付けています。送金の進み具合は、オンラインやアプリの「Track My Remittance」（送金の追跡）で確認できます（Global Money+の送金は対象外）。届くまでの日数は通常1〜4営業日とされています。

## まとめ

本記事の確認時点（2026年11月）では、ハンセン銀行から日本への送金手数料は、Personal e-BankingでHK$65、Global Money+でHK$160、支店などでHK$230〜270です。これとは別に、中継銀行や日本の銀行の手数料がかかる場合があります。オンラインで送る前には、受取人の住所や1日の上限の設定を確認しておくと手続きが進みます。日本で受け取った後の税金の考え方は[海外積み立ての税金](/blog/tax-on-offshore-savings)や[香港の預金利息と日本の税金](/blog/hsbc-hk-tax-japan)で解説しています。
