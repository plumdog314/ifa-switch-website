「海外積み立ての払い込み用に、シンガポールのシティバンクに口座を持っている。今もそのまま使えるのか、手数料はかかるのか」。こうした疑問をよく聞きます。結論から言うと、シティバンク（シンガポール）の個人向け業務は続いています。日本など海外に住む人の窓口は「International Personal Bank（IPB）」という部門です。口座を開くには新規資金でUS$200,000以上が必要です。残高がUS$200,000を下回ると、月US$50の手数料がかかります。

この記事では、シティの公式資料をもとに、本記事の確認時点（2026年11月）の内容を整理します。口座を開くことや、続けることを勧めるものではありません。

## シティバンク（シンガポール）は今も個人向けの営業を続けているの？

続いています。シティは2021年に、アジアなどの個人向け業務を4つの富裕層向け拠点（シンガポール、香港、UAE、ロンドン）に集中すると発表しました。その内容は[シティの2021年5月の発表](https://www.citigroup.com/global/news/press-release/2021/citi-on-track-with-wealth-ambitions-in-asia)で確認できます。撤退の対象は、オーストラリアやタイなど他の13の国・地域でした。

本記事の確認時点でも、[シティバンク（シンガポール）の公式サイト](https://www.citibank.com.sg/)では、口座の申し込みや各種サービスの案内が続いています。運営会社はCitibank Singapore Limitedです。

## 日本に住んでいても口座は開けるの？

海外在住者向けのIPBで申し込めます。ただし、日本在住の方はオンラインの申込書ではなく、連絡先を登録する方式です。

[IPBの申し込みページ](https://www.citibank.com.sg/international/apply-citigold-international-account)には「日本・マカオ・パキスタン・ベトナムにお住まいの方は、こちらに連絡先を残してください」という案内があります。登録すると、シティの担当者から条件や次の手順の説明があるとされています。日本語を話す担当者がいることも、同じページに書かれています。

同じページに載っている主な条件は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 預かり資産（AUM）の条件 | 新規資金でUS$200,000以上 |
| 年齢 | 18歳以上 |
| 口座の区分 | Citigold または Citigold Private Client |

AUM（Assets Under Management）とは、シティに預けている資産の合計です。普通預金・当座預金・定期預金・投資商品のほか、シティが販売するAIAシンガポールの生命保険の保険料が含まれるとされています。シティ以外の保険会社と直接結んだ海外積み立ての契約が含まれるとは書かれていません。

開設に必要な書類は、[本人確認（KYC）の書類](/blog/kyc-documents)の考え方が参考になります。ただし、シティの具体的な必要書類は公開資料では確認できませんでした。担当者に確認してください。

## 口座維持手数料はいくら？

TRBがUS$200,000未満だと、月US$50の手数料がかかります。TRB（Total Relationship Balance）とは、シティでの取引残高の合計です。[IPBの料金案内（Useful Information）](https://www.ipb.citibank.com.sg/global_docs/pdf/IPB_Useful_Info_Pricing.pdf)の「Account Service Fee」の欄に、こう書かれています。TRBは顧客単位で計算されます。

料金案内の主な項目を表にまとめます。

| 項目 | 金額 |
| --- | --- |
| 最低残高（TRB） | US$200,000 |
| TRBが最低残高を下回ったときの手数料 | 月US$50 |
| 開設から6か月以内の解約 | US$300 |
| 紙の利息明細（前年分） | S$15／通 |
| 小切手の支払い停止（シンガポールドル口座） | S$30／枚 |

この料金案内は「2025年2月から有効」と書かれ、2026年10月に印刷された版です。料金は予告なく変わることがあると明記されています。

なお、[料金・金利のページ](https://www.citibank.com.sg/static/banking-fees)では、シンガポールに住む人向けの料金表とIPB向けの案内が分かれています。シンガポール居住者向けの金額（月S$15など）は、IPBの口座には当てはまりません。

## 口座ごとの最初の預け入れ額は？

料金案内では、口座の種類ごとに最初に預ける金額の下限が決まっています。個人の場合の主なものは次のとおりです。

| 口座の種類 | 最初の預け入れ額（個人） |
| --- | --- |
| 普通預金（円・米ドル・豪ドルなど外貨） | US$5,000 |
| 普通預金（シンガポールドル） | S$5,000 |
| 当座預金（米ドル） | US$5,000 |
| 当座預金（シンガポールドル） | S$5,000 |
| 米ドル利付当座預金 | US$5,000 |

これとは別に、関係全体でUS$200,000の条件があります。口座ごとの下限を満たしても、手数料の条件は別に判定される点に注意が必要です。

## 預金は保険で守られるの？

シンガポールドル建ての預金だけが、1人あたりS$100,000まで守られます。料金案内には、シンガポール預金保険公社（SDIC）の制度について書かれています。外貨預金や仕組み預金、投資商品は対象外です。

日本の口座から円や米ドルで送ったお金は、外貨のまま置くと保険の対象外です。どの通貨で持っているかは、明細で確認できます。

## まとめ

シティバンク（シンガポール）は、シティが残すと決めた4つの拠点の1つで、本記事の確認時点（2026年11月）も個人向け業務を続けています。日本在住者の窓口はIPBです。開設には新規資金でUS$200,000以上が必要で、日本在住の方は連絡先の登録から始めます。TRBがUS$200,000未満だと月US$50の手数料がかかり、6か月以内の解約にはUS$300がかかります。
