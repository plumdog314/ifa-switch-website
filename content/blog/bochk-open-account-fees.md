「海外積み立てのために、中国銀行（香港）の口座を持てるのか知りたい」「今の口座に手数料がかかっていないか心配」。そんな疑問を持つ方に向けた記事です。結論から言うと、日本に住む方は、アプリではなく香港の支店か、日本の中国銀行の窓口を通じた手続きになります。個人の総合口座の月額手数料は、2019年8月1日に廃止されています。

中国銀行（香港）（Bank of China (Hong Kong) Limited、略してBOCHK）は、本記事の確認時点（2026年11月）で、個人向けの預金口座を[公式サイト](https://www.bochk.com/en/deposits/savings/savings.html)で案内しています。この記事は、公式の資料をもとに事実を整理したものです。口座を開くことや解約することを勧めるものではありません。

## 日本に住んでいても、アプリで口座を開ける？

開けません。アプリでの開設は、香港IDなどを持つ人に限られています。[アプリ開設の案内ページ](https://www.bochk.com/dam/more/accountopening/en.html)の条件は、主に次のとおりです。

- 香港の永住ID（HKID）を持ち、国籍が中国（香港・本土・マカオ）で、18歳以上
- または、中国本土の身分証と往来許可証を持ち、香港にいる18歳以上の人

同じページには、条件に合わない人や審査が通らなかった人は、支店で手続きするよう書かれています。

## 香港に行かずに開設する方法はある？

日本の中国銀行の支店で、見証（けんしょう）の手続きを受ける方法が案内されています。見証とは、銀行の窓口が本人確認と書類への署名に立ち会うことです。[見証による口座開設のページ](https://www.bochk.com/en/crossborder/personal/financialservicehk/account.html)では、対象の国・地域に日本が入っています。主な条件は次のとおりです。

| 項目 | 公式ページの内容 |
| --- | --- |
| 対象のサービス | Wealth Management、Enrich Banking |
| 対象者 | 18歳以上で、Wealth Managementの口座保有者、または中国銀行グループの一部の顧客 |
| 本人確認書類 | 外国籍の人は有効なパスポート |
| 住所の証明 | 必要な場合や投資口座を開く場合、3か月以内に公的機関や公共料金の会社が出した書類 |
| 申し込み方法 | 本人が窓口に行く（代理人は不可） |
| かかる期間 | 書類がそろえば、早くて約2週間 |

対象者の書き方は少しわかりにくいため、自分が当てはまるかは事前に銀行に確認が必要です。同じページには、見証を行う銀行の条件も満たし、追加の書類を出す必要があるとも書かれています。

日本の窓口は、[日本の見証窓口の一覧（2024年10月9日版）](https://www.bochk.com/dam/more/BOCTOKYO_EN.pdf)に、東京・大手町・横浜・名古屋・大阪の5つの支店が載っています。電話番号もこの一覧で確認できます。

なお、[普通預金のページ](https://www.bochk.com/en/deposits/savings/savings.html)には、中国銀行（香港）は口座開設の仲介業者を指定していないと書かれています。開設のときに、自分の情報を第三者に渡さないよう注意を呼びかけています。

## 口座の区分と、残高の条件は？

区分ごとに、取引残高の合計（TRB）の目安が決まっています。TRB（Total Relationship Balance）とは、預金や投資など、その銀行に預けている資産の合計額のことです。[2026年4〜6月のキャンペーン規約](https://www.bochk.com/dam/wm/2026q2/tnc_en.pdf)には、次の基準が載っています。

| 区分 | TRBの基準 |
| --- | --- |
| Private Wealth | HK$8,000,000以上 |
| Wealth Management | HK$1,000,000以上 |
| Enrich Banking | HK$200,000以上 |
| i-Free Banking | HK$10,000以上 |

同じ規約には、基準を満たせない場合、銀行が区分を変えたり外したりできると書かれています。その場合は、その区分の特典も受けられなくなります。

## 残高が少ないと、毎月の手数料はかかる？

本記事の確認時点（2026年11月）の公式資料では、個人の口座に残高不足の月額手数料は見当たりません。[アプリ開設のFAQ（2026年5月版）](https://www.bochk.com/dam/more/accountopening/images/faq_en.pdf)には、総合口座の月額手数料は2019年8月1日に廃止されたと書かれています。

[一般銀行サービスの料金表（2026年11月版）](https://www.bochk.com/en/servicecharge.html)でも、残高不足の月額手数料は「法人顧客のみ」の項目で、しかも免除と書かれています。ただし、ほかにかかりやすい手数料があります。

| 項目 | 料金 |
| --- | --- |
| 紙の総合明細書 | 1人あたり月HK$5（18歳未満・65歳以上などは免除） |
| 開設から3か月以内の解約 | 普通預金HK$50、当座預金HK$200（1口座あたり） |
| 過去の明細書の写し | 1回分HK$50（個人の総合明細書は銀行の判断で免除） |
| デビットカードの再発行 | HK$50 |

金額は[料金表のPDF](https://www.bochk.com/dam/document/TnC/DEP/servicecharge_en.pdf)でも確認できます。また[利用規約（Conditions for Services）](https://www.bochk.com/en/conditionsforservices.html)には、残高が基準より少ない口座や、長く動きのない口座に手数料をかけたり、金利をゼロにしたりすることがあると書かれています。動きのない口座については[中国銀行（香港）の口座が休眠になったら？](/blog/bochk-dormant-login)で整理しています。

## まとめ

日本に住む方は、中国銀行（香港）のアプリでは口座を開けません。香港の支店か、日本の中国銀行の見証窓口を通じた手続きになります。本記事の確認時点（2026年11月）では、個人の総合口座の月額手数料は廃止されています。残高が基準を下回ると、区分が変わることがあります。
