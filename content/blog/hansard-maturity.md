「ハンサードの積み立てが、もうすぐ満期になる。何もしなくてもお金は振り込まれるのか」。満期が近づくと、こうした疑問を持つ方が多いと思います。結論から言うと、Vantage Platinum II の契約条件書では、満期日に契約が終わり、その日の評価額が契約の通貨で支払われます。受け取るには、所定の書式で受取口座を届け出て、本人確認の書類をそろえる形です。満期の延長を申し込む書式もあります。

この記事は、ハンサードの公式資料で確認できた内容に絞っています。満期金の受け取り全般は[満期金はどうやって受け取る？](/blog/maturity-payout)で、満期前の運用の考え方は[満期が近づいたら運用をどう考える？](/blog/glide-path-before-maturity)で解説しています。

## 満期日には、契約はどうなるの？

満期日まで契約が続いていれば、契約はその日に終わり、契約の評価額が支払われます。Vantage Platinum II の[契約条件書（HO2479O、2025年11月版）](https://cdn.hansard.com/app/uploads/2024/03/HO2479O.pdf)の第28条に、次のように書かれています。

| 項目 | 契約条件書の記載 |
| --- | --- |
| 満期日 | 証券（Contract Certificate）に書かれた日 |
| 支払われる額 | 契約の評価額。前回の5年ごとの記念日以降に計算された、まだ付いていないボーナス口数も加える |
| 評価の日 | 満期日 |
| 通貨 | 契約の通貨 |
| 差し引き | 会社に払うべき金額があれば差し引く |

同じ条件書では、ボーナス口数は5年ごとの記念日と満期日に付くこと、5年分の積立金を満期までに払っていないとウェルカムボーナス分の口数が取り消されることも定められています。契約者は満期時に75歳以下である必要があるとも書かれています。

ただし、これは本記事の確認時点（2026年11月）で公式サイトに載っている版です。契約した時期や商品によって条件は違います。たとえば、Ascend の[契約条件書（HO2588O）](https://cdn.hansard.com/app/uploads/2024/11/HO2588O.pdf)には、満期日についての条項が見当たりませんでした。ご自身の証券と契約条件書で確認してください。

## 満期金を受け取るには、何を出すの？

「Request for Maturity Proceeds」という書式で、受取口座などを届け出ます。契約している会社ごとに版があります。

| 契約している会社 | 書式 |
| --- | --- |
| Hansard International Limited | [HO2428O](https://cdn.hansard.com/app/uploads/2024/03/HO2428O.pdf) |
| Hansard Worldwide Limited | [HWL187](https://cdn.hansard.com/app/uploads/2024/03/HWL187.pdf) |

書式には、契約者の氏名・住所・契約番号、受取口座（銀行名・国・口座名義・口座番号・SWIFTコードなど）を書きます。口座の国が住んでいる国と違う場合は、その理由も書きます。中継銀行（送金の途中で経由する銀行）が必要な場合は、その情報も書きます。最後に契約者全員が署名します。

本人名義の口座に送る場合は、書式を電子的なコピー（アップロードやメール）で出せば支払いの手続きを始められると書かれています。原本の送り先は、マン島の管理センター（55 Athol Street, Box 192, Douglas, Isle of Man, IM99 1QL）です。

## 本人確認の書類は、また出す必要があるの？

場合によります。書式の案内では、2年以内に出した書類が今も有効なら（本人確認書類の期限が切れておらず、住所も同じなら）、追加の書類は不要とされています。2年より前に出した場合、書類の期限が切れた場合、最近引っ越した場合は、新しい認証付きの書類が必要です。

| 書類 | 書式の記載 |
| --- | --- |
| 本人確認 | 有効なパスポートか国民IDカード。ない場合は、税務の通知書や運転免許証など2点の認証付きコピー |
| 住所の確認 | 公共料金の請求書、銀行やクレジットカードの明細、税務の書類など。発行から6か月以内 |
| 認証する人 | ハンサードが認めたIFA、大使館・領事館の職員、公証人、弁護士、会計士など |

認証の考え方は[本人確認・住所証明の提出を求められたら](/blog/kyc-documents)で解説しています。

## いつ、どのように支払われるの？

書式の注意事項には、次の点が書かれています。

- 口数は、満期日（またはその次に使える日）の価格と為替レートで売却される
- 価格の算出が止まっているファンドの分は、再開するまで満期金に含まれない
- 満期後、支払いの準備に5営業日かかる
- 指定の口座への送金には、銀行の送金手数料がかかる
- 満期日から3か月以内に書類がそろわない場合、新しい指示を求めることがある

受取口座は、オンライン口座の「Profile」から「Bank Details」でも登録できます。[口座変更のガイド（HG0131O）](https://cdn.hansard.com/app/uploads/2026/05/HG0131O-1.pdf)では、日本の銀行の場合、SWIFTコード、口座番号、支店コード（Sort Codeの欄に入力）、支店名を入れるよう案内されています。海外からの送金を受け取れるかは、事前に自分の銀行に確認するよう書かれています。価格が止まったファンドについては[ファンドが取引停止になったら](/blog/suspended-fund)をご覧ください。

## 満期を延ばすこともできるの？

「Request to extend a maturing contract」という書式で、延長を申し込めます（Hansard International は[HO1576O](https://cdn.hansard.com/app/uploads/2024/03/HO1576O.pdf)、Hansard Worldwide は[HWL357](https://cdn.hansard.com/app/uploads/2025/08/HWL357.pdf)、いずれも2025年8月版）。書式に書かれた延長の条件は次のとおりです。

| 項目 | 書式の記載 |
| --- | --- |
| 延長の期間 | 元の満期日から5年 |
| 積立金 | 払えなくなる（届いたお金は手数料を引いて返す） |
| 口数 | 満期日の初期口数とボーナス口数は、アキュムレーター口数に替える |
| 費用 | 払込を止めた契約の水準でサービス手数料が続く。運用管理費は現在、シリーズ1のファンドで年1%、シリーズ2で年1.5% |
| ボーナス | 新しいボーナス口数は付かない |
| 申込期限 | 満期日の10営業日前までに届く必要がある。延長を選べるのは満期日まで |

書式はメールで送れますが、原本も本社に郵送する必要があるとされています。IFAの助言を受けたかどうかを選ぶ欄もあります。

## まとめ

Vantage Platinum II の契約条件書では、満期日に契約が終わり、その日の評価額が契約の通貨で支払われます。受け取りは「Request for Maturity Proceeds」で口座を届け出て、必要なら新しい本人確認書類を出す形です。延長の書式もありますが、満期日の10営業日前が期限です。満期金の税金は[満期金を受け取ったときの税金](/blog/tax-on-maturity)をご覧ください。
