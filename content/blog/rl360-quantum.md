RL360の「クォンタム（Quantum）」は、日本人の保有者が多い海外積み立てプランです。「仕組みがよく分からないまま払い続けている」という声もよく聞きます。結論から言うと、クォンタムは、契約初期の積立金が初期口座（イニシャルユニット：最初の期間に払った分。手数料が重い）に充てられ、満期まで手数料と解約控除（早く解約したときに差し引かれる費用）の対象になる構造の商品です。ここでは、RL360の資料に基づいて中立的に整理します。

## クォンタムはどんな商品なの？

クォンタムは、マン島のRL360が提供していた、毎月または定期的に積み立てる保険商品です。積立金は、契約者が選んだファンドの値動きに連動して増減します。RL360の[公式サイト](http://rl360.com/row/products/quantum/quantum.htm)によると、2019年7月1日に新規の申し込みの受付を終了しており、既存の契約者は追加の払い込みやファンドの入れ替え（スイッチ）を続けられます。

以下は、RL360の[クォンタムの重要事項説明書（2016年頃の版）](https://www.rl360.com/generic/downloads/rl360-quantum-key-features-review.pdf)に基づく内容です。契約の時期によって条件が異なる可能性があるため、最終的にはご自身の契約条件書を確認してください。

| 項目 | 内容 |
| --- | --- |
| 契約の形 | 生命保険型、またはキャピタル・リデンプション型（被保険者のいない形） |
| 通貨 | 英ポンド、ユーロ、米ドル、香港ドル、日本円など（契約後は変更不可） |
| 構成 | 最大100のサブ・ポリシー（小さな契約）に分けることができる |
| ファンド | 多数のファンドから選択。オンライン登録なしの場合は最大10本 |
| スイッチ | オンラインならいつでも無料 |

## 初期口座期間はどう決まるの？

初期口座期間は、契約期間の長さで決まります。この期間の積立金は、すべて初期口座（Initial units）に充てられます。

| 契約期間 | 初期口座期間 |
| --- | --- |
| 5〜18年 | 18か月 |
| 19年 | 19か月 |
| 20年 | 20か月 |
| 21〜23年 | 21〜23か月（1年ごとに1か月ずつ増える） |
| 24年以上 | 24か月 |

初期口座期間の後の積立金は、積立口座（Accumulation units：初期口座の後に払った分）に充てられます。また、積立額を増やすと、増えた分にも新たな初期口座期間が設定されます。2つの口座の違いは[初期口座と積立口座の違い](/blog/initial-vs-accumulation-units)で解説しています。

## 手数料はどうかかるの？

資料に記載されている主な手数料は次のとおりです。

| 手数料 | かかり方 |
| --- | --- |
| 初期口座の手数料 | 初期口座の価値に対して月0.50％、積立期間を通して |
| 管理手数料 | 評価額に対して月0.125％ |
| 毎月の固定手数料 | 米ドル建てで月8ドル（マン島の物価指数に連動して毎年改定） |
| 払い込み停止中の固定手数料 | 米ドル建てで月24ドル |

このほかに、ファンドごとの運用管理費用がかかります。初期口座期間中は、固定手数料が積立口座から差し引かれるため、評価書で積立口座の口数がマイナスになることがあります。積立期間が10年以上の契約では、満期時に一定の長く続けた人への上乗せ（ロイヤルティボーナス）が加算される仕組みもあります。

## 引き出しはできるの？

引き出しは、初期口座期間が終わり、積立口座に価値が積み上がってから可能になります。

- **定期的な引き出し**：1回あたりの最低額があり（米ドル建てで400ドル）、1年間の合計は年初の評価額の10％まで
- **一回限りの引き出し**：積立口座の価値の範囲内で、評価額が最低額（米ドル建てで8,000ドル）を下回らないこと

具体的な手続きは[積み立てから一部引き出したいときの手続き](/blog/partial-withdrawal)をご覧ください。

## 途中で解約すると、どうなるの？

初期口座期間中に解約すると解約返戻金（解約したときに戻ってくるお金）はなく、実質100％の解約控除になると明記されています。初期口座期間の後は、初期口座の価値に解約控除がかかり、その割合は満期までの残り年数が長いほど大きくなります。資料の表では、残り5年で34％、残り10年で56.5％、残り20年で81％です。積立口座の部分には、この控除はかかりません。

契約から2年前後で解約した場合の考え方は[RL360の2年後に解約するとどうなる？](/blog/rl360-surrender-after-2-years)で具体的に解説しています。

## 生命保険型とキャピタル・リデンプション型は、何が違うの？

クォンタムには、2つの契約の形がありました。どちらの形かによって、契約が終わる条件が違います。

| 項目 | 生命保険型 | キャピタル・リデンプション型 |
| --- | --- | --- |
| 被保険者 | いる（1人、または2人のうち最後の人） | いない |
| 契約が終わるとき | 最後の被保険者が亡くなったとき、または解約したとき | 最長99年の満了時、または解約したとき |
| 終了時に支払われる額 | 資料の定めによる | 満了時は評価額に一定額を加えた額 |

キャピタル・リデンプション型は、契約者が亡くなっても自動的には終わらず、その扱いは遺産の手続きの中で決まると説明されています。どちらの形かは、契約書類（ポリシースケジュール）で確認できます。

また、クォンタムは最大100のサブ・ポリシーに分けて作ることができました。初期口座期間の後は、サブ・ポリシー単位で解約することも可能とされています。この場合も、解約するサブ・ポリシーの初期口座には解約控除がかかります。一部だけ資金が必要なときの選択肢の一つとして、仕組みを知っておくとよいでしょう。
