「シンガポールのDBS銀行に口座を作りたいけれど、日本に住んでいても開けるの？」。海外積み立ての受け取り口座を考えている方から、こうした質問を受けます。結論から言うと、DBSの一般の口座開設の案内は、シンガポールのパスを持つ人が前提です。日本在住の人には、富裕層向けのDBS Treasuresの窓口から遠隔で開設を申し込む方法が案内されています。

この記事では、DBS銀行（DBS Bank Ltd）の公式サイトと[預金の手数料表（Deposits Guide、2026年6月版）](https://www.dbs.com.sg/iwov-resources/pdf/deposits/DBS_deposit_guide.pdf)をもとに、本記事の確認時点（2026年11月）の内容を整理します。DBSは本記事の確認時点で、シンガポールで個人向けの銀行業務を続けています。口座を開くかどうかを勧めるものではありません。

## 日本に住んでいても、DBSの口座は開けるの？

一般の口座は、シンガポールのパスを持たないと開けない案内になっています。パスとは、シンガポール政府が出す就労や滞在の許可証のことです。

DBSの[外国人向けの案内ページ](https://www.dbs.com.sg/personal/deposits/for-foreigners/new-to-singapore)では、必要なものとして次が挙げられています。

- パスポート
- 有効なパス（Employment Pass、S Pass、Student Passなど。いずれも就労や留学のためのパス）。発行前の仮承認の通知（In-Principle Approval）も可
- 住所を確認できる書類
- 日本などほかの国の税金の居住者である場合は、それを示す書類

[必要書類のページ](https://www.dbs.com.sg/personal/support/bank-account-opening-documents-required.html)には、シンガポールの住所がまだない場合は海外の住所で申し込める、という記載があります。ただしこれは、パスを持ってシンガポールに移る人を想定した案内です。パスのない日本在住の人が、この方法で開けるとは書かれていません。

## シンガポールに住んでいない人には、どんな窓口があるの？

DBSは、シンガポールと香港のどちらにも住んでいない外国人向けに、遠隔での口座開設を案内しています。[DBS Treasures Internationalのページ](https://www.dbs.com/global-wealth/dbs-treasures-international.html)に書かれている主な条件は、次のとおりです。

| 項目 | 公式ページの記載 |
| --- | --- |
| 対象 | シンガポール・香港の国籍がなく、住んでもいない外国人 |
| 開設の方法 | 遠隔での開設が可能 |
| 新規顧客の資産の目安（シンガポール） | 投資に回せる資産S$350,000 |
| 書類 | パスポート、住所と郵送先の確認書類など |
| 書類の証明 | DBSの顧客でない場合、第三者の公証が必要 |

公証とは、公証人などの第三者が書類の写しが本物だと証明する手続きのことです。申し込みはページ内の問い合わせ用の入力フォームから行い、3営業日以内に返事が来ると書かれています。日本の住所でどこまで対応できるかは、公式ページでは確認できませんでした。必要書類の考え方は[本人確認の書類（KYC）とは？](/blog/kyc-documents)でも整理しています。

## 口座の種類ごとの最低残高と手数料は？

多くの口座で、1か月の平均残高が決められた額を下回ると、毎月の手数料がかかります。DBSの[最低残高の案内ページ](https://www.dbs.com.sg/personal/support/bank-deposit-accounts-fall-below-fee.html)の主な内容です。

| 口座の種類 | 最低の平均残高 | 下回ったときの月の手数料 |
| --- | --- | --- |
| DBS My Account | S$0 | 紙の明細書を受け取る場合S$2 |
| DBS Multiplier Account | S$3,000 | S$5 |
| DBS eMulti-Currency Autosave Account など | S$3,000 | S$7.50 |
| DBS Expatriate（駐在員向け）の各口座 | S$5,000 | S$7.50 |
| DBS Savings Account（2011年9月12日以降の開設） | S$1,000 | S$2 |
| POSB eSavings / Everyday / Passbook Savings | S$500 | S$2 |

外貨も持てる口座では、すべての通貨の残高をシンガポールドルに換算した合計で判定されます。平均残高は、毎日の終わりの残高を足して、その月の日数で割って出します。

[手数料表](https://www.dbs.com.sg/iwov-resources/pdf/deposits/DBS_deposit_guide.pdf)では、Multiplierの手数料は29歳以下なら免除です。My Accountの月S$2は、16歳以下なら免除です。またMulti-Currency Autosave Plusなど一部の口座には、この手数料とは別に月S$2〜S$4の口座手数料があります。駐在員向けの口座や、DBS Current Accountなど、新しく開けなくなった口座も多くあります。

## 資産が多い人向けのDBS Treasuresの条件は？

DBS Treasuresは、月末の預金と投資の合計S$200,000が基準です。下回ると月S$50の手数料がかかり、3か月ごと（1月・4月・7月・10月）にまとめて引かれると[最低残高の案内ページ](https://www.dbs.com.sg/personal/support/bank-deposit-accounts-fall-below-fee.html)に書かれています。合計には預金、投資、一時払いの保険などが含まれます。

ただし、前の章のとおり、海外に住む新規の顧客にはS$350,000という別の目安が示されています。どちらの基準が自分に当てはまるかは、DBSに確認が必要です。

## ほかに、知っておきたい手数料は？

開いてから6か月以内に閉じると、口座の解約手数料S$30がかかる場合があります。[手数料表](https://www.dbs.com.sg/iwov-resources/pdf/deposits/DBS_deposit_guide.pdf)では、外貨の当座預金（Foreign Currency Current Account）の欄にこの項目があります。

| 項目 | 手数料 |
| --- | --- |
| 海外からの送金の受け取り（電信送金） | S$10 |
| 明細書などの再発行（1年以内） | 1通S$20 |
| 残高証明などの発行 | S$21.80（税込） |
| 確認用の番号を出す小さな機器（iB Secure Device）の再発行 | S$20 |

日本への送金の手数料は[DBS銀行（シンガポール）から日本へ送金するには？](/blog/dbs-sg-transfer-to-japan)で整理しています。また、シンガポールの銀行の利息にも日本の税金がかかります。考え方は[海外の銀行の利息に日本の税金はかかる？](/blog/hsbc-hk-tax-japan)をご覧ください。海外の口座の情報が日本の税務署に共有されるしくみは[CRSとは？](/blog/crs-explained)で解説しています。

## まとめ

DBS銀行（シンガポール）の一般の口座は、シンガポールのパスを持つ人向けの案内です。シンガポールにも香港にも住んでいない外国人には、DBS Treasuresの遠隔開設の窓口があり、資産S$350,000が目安です。本記事の確認時点（2026年11月）では、多くの口座で平均残高が基準を下回ると月S$2〜S$7.50の手数料がかかります。すでに口座を持っている方も、最低残高を一度確認しておくと安心です。
