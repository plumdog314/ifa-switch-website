「まとまった量のゴールドを売ると、税務署に連絡がいくって本当？」「マイナンバーを求められたのはなぜ？」。ゴールドを売ろうとすると、こうした疑問が出てきます。

結論から言うと、ゴールドの売買を業とする買取業者が、ゴールドの延べ棒（地金）や金貨の代金として200万円を超えて支払うと、税務署に「支払調書」を提出します。売る人は、氏名・住所・マイナンバーを業者に伝える必要があります。この記事では、国税庁の資料と所得税法をもとに、仕組みを整理します。

## 「金地金等の譲渡の対価の支払調書」とは？

ゴールドの買取業者が、誰にいくら支払ったかを税務署に報告する書類です。平成24年（2012年）1月1日から始まりました。

支払調書とは、お金を支払った側が、支払った相手や金額を税務署に報告する書類のことです。法律で提出が決められているため「法定調書」とも呼ばれます。

国税庁の[金地金等に係る譲渡所得の調査状況](https://www.nta.go.jp/information/release/kokuzeicho/2015/shotoku_shohi/sanko04_05.htm)では、この支払調書について、平成24年1月1日以降、ゴールドの延べ棒など（金地金等）の売買を業として行う者が、国内でゴールドの延べ棒などを買い取り、200万円超の代金を支払う場合に、税務署へ提出する義務があると説明されています。

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 提出する人 | 国内でゴールドの延べ棒などの代金を支払う、ゴールドの延べ棒などの売買を業として行う者 | [国税庁 F1-42](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/1251.htm) |
| 対象になる支払 | 200万円を超える代金 | [国税庁の発表](https://www.nta.go.jp/information/release/kokuzeicho/2015/shotoku_shohi/sanko04_05.htm) |
| 提出の時期 | 支払が確定した日の翌月末日まで | [国税庁 F1-42](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/1251.htm) |
| 提出先 | 業者の納税地を管轄する税務署 | [国税庁 F1-42](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/1251.htm) |
| 法律の根拠 | 所得税法第225条第1項第14号 | [国税庁 F1-42](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/1251.htm) |

提出するのは買取業者で、売る人が自分で税務署に出す書類ではありません。また、多くの法定調書は年1回まとめて出しますが、この支払調書は支払のたびに、翌月末までに出す仕組みです。

## どんなゴールドが対象になるの？

ゴールドの延べ棒だけでなく、プラチナの延べ棒、金貨、プラチナ貨も対象です。

[所得税法第224条の6](https://laws.e-gov.go.jp/law/340AC0000000033)では、「金若しくは白金の地金又は金貨若しくは白金貨」をまとめて「金地金等」としています。白金とはプラチナのことです。国税庁の[支払調書の記載要領（PDF）](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/pdf/r08/kisai_chousho42.pdf)にも、種類の欄には「金地金、白金地金、メープル金貨、イーグル白金貨」のように書くと示されています。

ゴールドのアクセサリーなどの宝飾品が対象になるかは、本記事の確認時点（2026年11月）では、国税庁の資料で明確に確認できませんでした。

## 支払調書には、何が書かれるの？

売った人の住所・氏名・マイナンバーと、売ったゴールドの種類、重さ、数量、支払金額、支払が確定した日が書かれます。

国税庁の[支払調書の記載要領（PDF）](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hotei/pdf/r08/kisai_chousho42.pdf)をもとにまとめると、次のとおりです。

| 記載される項目 | 内容 |
| --- | --- |
| 住所（居所）・氏名 | 支払調書を作る日の時点の住所 |
| 個人番号 | 売った人のマイナンバー |
| 売ったゴールドなどの種類 | ゴールドの延べ棒、メープル金貨など |
| 重量 | 1単位あたりの重さ |
| 数量 | 売った個数 |
| 支払金額 | 支払が確定した代金の額 |
| 支払確定年月日 | 支払が確定した日 |

この支払調書は、日本の居住者などに支払う代金について使うとされています。

## 売る人は、何をする必要があるの？

200万円を超える代金を受け取る人は、受け取るまでに、氏名・住所・マイナンバーを業者に伝え、本人確認書類を示す必要があります。

[所得税法第224条の6](https://laws.e-gov.go.jp/law/340AC0000000033)では、ゴールドの延べ棒などを売って代金を受け取る人は、受け取るべき時までに、氏名・住所・個人番号を、ゴールドの延べ棒などの売買を業として行う買取業者に告知しなければならないと定めています。あわせて、住民票の写しなどの書類を示すこと、業者はその書類で内容を確認することも定められています。対象から外れる金額は政令で定めるとされています。

マイナンバーの確認方法について、国税庁の[本人確認に関するFAQ](https://www.nta.go.jp/taxes/tetsuzuki/mynumberinfo/FAQ/honninkakunin_qa.htm)では、マイナンバーカードがあれば、番号の確認と本人の確認がこのカードだけでできると案内されています。具体的にどの書類を求めるかは、業者に確認してください。

## 200万円以下なら、税金は関係ないの？

関係あります。200万円は支払調書を出す基準であって、税金がかかるかどうかの基準ではありません。

国税庁の[タックスアンサー No.3161](https://www.nta.go.jp/taxes/shiraberu/taxanswer/joto/3161.htm)では、ゴールドの延べ棒を売ったもうけは、原則として総合課税の譲渡所得とされています。売った金額で区別はされていません。総合課税の譲渡所得には年50万円の特別控除があるなど、計算のしかたは[ゴールドを売ったときの税金はどうなる？](/blog/tax-on-selling-gold)で解説しています。

## 税務署は、この情報をどう使っているの？

国税庁は、支払調書などの情報をもとに、ゴールドの延べ棒などの売却について調査をしていると公表しています。

国税庁の[発表](https://www.nta.go.jp/information/release/kokuzeicho/2015/shotoku_shohi/sanko04_05.htm)では、支払調書のほか、さまざまな機会に情報を集めて調査をしていると書かれています。平成26事務年度（2014年7月〜2015年6月）のゴールドの延べ棒など（金地金等）の譲渡所得の調査では、申告漏れなどの件数が2,627件、申告漏れの所得金額が117億円と公表されています。これより新しい全国の数字は、本記事の確認時点では見つけられませんでした。
