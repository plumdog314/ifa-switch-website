「シンガポールのシティバンクにある資金を、日本の口座に移したい」。海外積み立ての満期金や解約金を受け取った方から、よく聞く相談です。結論から言うと、アプリかオンラインバンキングの電信送金（Telegraphic Transfer）で送れます。円での送金は最大3営業日かかり、1日の上限はS$250,000です。

この記事では、シティの公式案内と海外在住者向け部門IPB（International Personal Bank）の料金案内をもとに、本記事の確認時点（2026年11月）の内容を整理します。

## どうやって日本に送金するの？

アプリかオンラインバンキングで、電信送金を選んで送ります。[シティの送金の案内ページ](https://www.citibank.com.sg/personal-banking/online-services/online-payments)は、シンガポール居住者とIPBの両方のお客様向けと明記されています。アプリでの手順は次のとおりです。

1. Citi Mobileアプリにログインし、「Payments」を開く
2. 「Overseas Transfer」を選び、必要なら「New Payee（新しい送金先）」を追加する
3. 通貨と金額を入れる
4. 内容を確かめて確定する

パソコンのオンラインバンキングでは、「Payments & Transfers」から送金先を追加します。「Payee Type」で「Telegraphic Transfer」を選びます。新しい送金先の追加には、アプリの強化セキュリティかセキュリティ端末（OSD）での認証が必要です。認証の詳細は[ログインできないときの記事](/blog/citibank-sg-dormant-login)をご覧ください。

## 送金にはどんな情報が必要なの？

受取人と受け取る銀行の情報が必要です。[IPBの送金依頼書（Application for Funds Transfer）](https://www.ipb.citibank.com.sg/global_docs/pdf/Application_For_Funds_Transfer_Form.pdf)には、次の欄があります。

| 項目 | 内容 |
| --- | --- |
| 受取人の名前・住所 | 日本の口座の名義と住所 |
| 銀行名・支店名、銀行の住所 | 受け取る日本の銀行 |
| 口座番号 | 受け取る口座の番号 |
| SWIFTコード | 銀行を国際的に見分けるための番号 |
| メッセージ | 必要に応じて記入 |

SWIFTコードとは、海外送金で銀行を特定するための8〜11桁の番号です。日本の銀行のコードは、受け取る銀行のサイトなどで確認してください。

## いつ届くの？上限はある？

円での送金は、指示した日から最大3営業日かかるとされています。案内ページでは、円は「Group 1」の通貨に入っています。主な条件は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 送れる通貨 | 41通貨（円・米ドル・シンガポールドルなど） |
| 届くまでの目安（円など） | 最大3営業日 |
| 1日の上限 | S$250,000 |
| 利用できる時間 | 24時間（月〜土の6:30〜8:00はシステム停止） |

上限の範囲内で、自分で1日の上限を低く設定することもできます。なお、シティの口座どうしで無料ですぐに送れる「Citibank Global Transfer」の対象は、香港・シンガポール・UAE・米国です。日本は入っていません。

## 手数料はいくら？

オンラインの電信送金は、シティの案内では「1件ごとの定額の手数料で、追加の手数料率（commission）はかからない」とされています。中継銀行や受け取る銀行の手数料は別にかかることがあります。ただ、IPB向けのオンライン送金の具体的な金額は、確認時点では公開資料で確認できませんでした。確定前の画面や担当者で確認してください。

[IPBの料金案内（Useful Information）](https://www.ipb.citibank.com.sg/global_docs/pdf/IPB_Useful_Info_Pricing.pdf)で確認できた項目は次のとおりです。

| 項目 | 手数料 |
| --- | --- |
| 支店での電信送金（両替あり） | 送金額の1/8%（最低S$20）＋電信料など |
| 支店での電信送金（両替なし） | 1/8%（最低S$20）＋両替代わりの手数料1/8%（最低S$10）＋電信料など |
| 「OUR」を選んだ場合の手数料（Citibanking・Citigold） | 送金額S$10,000未満はS$10、S$10,000以上はS$25 |
| 「OUR」を選んだ場合の手数料（Citigold Private Client） | S$10 |

「OUR」とは、中継銀行や受け取る銀行の手数料まで送り主が払う方法です。料金案内には、実際の相手側の手数料がこの金額より高くても低くても、差額の調整はしないと書かれています。

## 手数料の負担方法は、どう選ぶの？

送金依頼書では、「SHA」「BEN」「OUR」の3つから選びます。

- **SHA**：シティの手数料は送り主、相手側の手数料は受取人が払う
- **BEN**：すべての手数料を受取人が払う（送金額から差し引かれる）
- **OUR**：すべての手数料を送り主が払う

何も選ばないとSHAになります。また、口座の解約のための送金や、送金後の残高がゼロになる場合はBENになると書かれています。OURは解約のときは使えません。解約の流れは[口座の解約と、名義人が亡くなったときの記事](/blog/citibank-sg-close-account-death)で解説しています。

## 日本で受け取るときに知っておくことは？

100万円を超える送金は、日本の銀行から税務署に報告されます。[国税庁の資料](https://www.nta.go.jp/about/introduction/torikumi/report/2026/04_4.htm)によると、送金者と受取人の名前・住所・金額などを書いた「国外送金等調書」を、送金を扱った金融機関が税務署に出します。

また、海外の預金の利息や、海外積み立ての解約金には、日本の税金がかかることがあります。[海外口座の利息にかかる税金](/blog/hsbc-hk-tax-japan)や[海外積み立ての税金](/blog/tax-on-offshore-savings)をご覧ください。

## まとめ

シティバンク（シンガポール）から日本へは、アプリかオンラインの電信送金で送れます。円は最大3営業日、1日の上限はS$250,000です。手数料の負担方法はSHA・BEN・OURから選び、OURを選ぶとIPBのCitigoldでは送金額に応じてS$10かS$25がかかります。相手側の手数料は別にかかることがあり、100万円を超える受け取りは日本の銀行から税務署に報告されます。
