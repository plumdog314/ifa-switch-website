「何となく将来のために積み立てているけれど、これで足りるのか分からない」。そんな不安を感じている方は多いと思います。結論から言うと、投資の目標は「いくら・いつまでに・どう使うか」の3点を先に決め、そこから毎月の金額と期間を逆算するのが基本です。ゴールがあると、相場が荒れたときの判断もぶれにくくなります。

## なぜゴールを先に決めるの？

ゴールがないと、良し悪しを判断する物差しがないからです。

たとえば評価額が20%下がったとき、ゴールがない人は「怖い」という感情だけで判断しがちです。ゴールがある人は「受け取りは20年後だから、今の下げはまだ取り戻す時間がある」と考えられます。同じ下落でも、ゴールまでの距離によって意味が変わります。

| ゴールがない場合 | ゴールがある場合 |
| --- | --- |
| 評価額の上下だけで一喜一憂する | 目標に間に合うかで判断できる |
| 他人の成績と比べて焦る | 自分の計画と比べられる |
| やめる・続けるの基準がない | 見直す条件を事前に決められる |

## ゴールはどんな手順で決める？

次の4ステップで考えると整理しやすくなります。

1. **目的を書き出す**：老後の生活費、子どもの教育費、住宅の購入など
2. **時期を決める**：何歳のとき、何年後に必要か
3. **金額を見積もる**：必要な総額から、年金や預金など他で用意できる分を引く
4. **取り崩し方を決める**：一度に使うのか、毎月少しずつ使うのか

最初から正確でなくて構いません。おおまかな数字でも、ないよりはずっと判断しやすくなります。

## 目標額から毎月の積み立て額を逆算すると？

ここでは、25年後に2,000万円を用意したいという例で計算します。

**前提：25年間、毎月同じ金額を積み立て、利回りは一定（月複利）と仮定。手数料・税金・為替は考慮なし。**

| 想定する年利 | 必要な毎月の積み立て額 | 25年間で払う合計 |
| --- | --- | --- |
| 0%（増えない） | 約6.67万円 | 約2,000万円 |
| 3% | 約4.48万円 | 約1,344万円 |
| 5% | 約3.36万円 | 約1,008万円 |

利回りの前提が2%違うだけで、毎月の必要額は1万円以上変わります。実際の市場は毎年一定には動かず、手数料も差し引かれます。そのため、控えめな利回りでも計算しておくと、計画が崩れにくくなります。利回りの前提の落とし穴は[シミュレーション通りにいかない理由](/blog/why-not-like-simulation)で詳しく扱っています。

## 出口（取り崩し方）まで考えるとどう変わる？

貯めたお金をどう使うかで、必要な準備も変わります。2,000万円を20年かけて毎月取り崩す場合を比べます。

**前提：2,000万円を20年（240か月）で毎月同額ずつ取り崩す。残高の運用利回りは一定と仮定。手数料・税金は考慮なし。**

| 取り崩し中の年利 | 毎月使える金額の目安 |
| --- | --- |
| 0%（運用しない） | 約8.33万円 |
| 3% | 約11.09万円 |

取り崩しの間も運用を続ければ、毎月使える金額は増える可能性があります。一方で、取り崩しの時期に大きな下落があると影響を受けやすくなります。出口が近づいたときの考え方は[出口に向けたポートフォリオの変え方](/blog/glide-path-before-maturity)をご覧ください。

海外積み立ての場合は、満期の受け取り方（一時金か、分割か）によって日本の税金の扱いも変わることがあります。基本は[満期で受け取るときの税金](/blog/tax-on-maturity)で解説しています。具体的な税額は税理士に確認してください。

## ゴールを決めたら、何を点検すればいい？

年に1回、次の3点を確認するだけで十分です。

- 目標額と時期は今も変わっていないか
- 今のペースで目標に近づいているか
- 受け取りまでの残り期間に対して、値動きの大きさは合っているか

ゴールを持っていても、毎日評価額を見る必要はありません。点検の頻度については[評価額は毎日見た方がいい？](/blog/dont-check-too-often)で考え方を紹介しています。ご自身の契約と目標を整理したい方は[AIチャット](/chat)もご利用ください。

## 目標額が大きすぎて、とても届きそうにないときは？

逆算した結果、毎月の必要額が家計の負担になる金額だった、ということはよくあります。そのときに取れる考え方は、主に4つです。

| 調整できること | 考え方の例 |
| --- | --- |
| 時期 | 受け取る時期を数年後ろにずらす |
| 金額 | 必要額を見直し、優先順位の低い目的を外す |
| ほかの資金 | 退職金や年金の見込みを確認し、積み立て以外で用意できる分を増やす |
| 取り崩し方 | 一度に使わず、長い期間に分けて使う |

高い利回りを前提にして目標を合わせるのは、逆にリスクを高めることになりがちです。利回りの前提ではなく、時期・金額・取り崩し方の側で調整するのが、計画を崩さないためのコツです。

目標は一度決めたら終わりではありません。調整した結果も、年1回の点検で見直していけば、少しずつ現実に合った計画になっていきます。最初から完璧な数字を目指すより、おおまかな目標を持って始め、毎年修正していく方が続けやすいでしょう。

## まとめ

投資のゴールは「いくら・いつまでに・どう使うか」を先に決めることで具体的になります。目標額から逆算すると、利回りの前提によって必要な積み立て額が大きく変わることが分かります。控えめな前提で計算し、年1回見直すことで、相場に振り回されない長期投資の土台ができます。
