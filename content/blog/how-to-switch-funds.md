「ポートフォリオを見直したいが、どう手続きすればいいのか分からない」「担当者がいなくなって、自分でできるのか不安」という声をよく聞きます。結論から言うと、ファンドの入れ替えは保険会社のオンライン画面か所定の書類で、契約者自身でも行えることが一般的です。ここでは、どのファンドを選ぶかではなく、手続きの仕組みを解説します。

## ファンドの変更には、どんな種類があるの？

ファンドの変更には2種類あります。この2つを区別することが、いちばん大切なポイントです。

| 種類 | 英語の表記の例 | 何が変わるか |
| --- | --- | --- |
| スイッチ | Switch | すでに持っている口数を売って、別のファンドを買う |
| 配分変更 | Redirection / Premium allocation | これから払う積立金で買うファンドの割合を変える |

たとえば、スイッチだけをして配分変更をしないと、翌月からの積立金は以前のファンドを買い続けます。逆に、配分変更だけでは今ある資産の中身は変わりません。両方を行うかどうかを、目的に合わせて決める必要があります。

## スイッチの手続きはどう進めるの？

一般的な流れは次のとおりです。

| 手順 | 内容 |
| --- | --- |
| 1. 現状を確認 | 評価書で、保有ファンド・口数・割合を確認する |
| 2. 方法を選ぶ | オンライン画面か、書類（スイッチ依頼書）かを選ぶ |
| 3. 内容を記入 | 売るファンドと割合（または口数）、買うファンドと割合を指定する |
| 4. 配分変更も指定 | 今後の積立金の配分も変えるかどうかを指定する |
| 5. 完了を確認 | 取引完了の通知と、変更後の評価書で結果を確認する |

RL360の場合、[クォンタムの重要事項説明書（2016年頃の版）](https://tailormadepensions.eu/wp-content/uploads/2017/01/RL360-Quantum-Savings-Plan-Key-Features.pdf)では、オンラインのスイッチ機能を使えばいつでも無料でスイッチや配分変更ができ、登録していない場合は最大10本までのファンドに投資できると書かれています。書類で行う場合は、保険会社の書類ダウンロードページにあるスイッチ依頼書を使うのが一般的です。

## スイッチに手数料はかかるの？

商品によって異なります。RL360の[Regular Savings PlanのFAQ](https://www.rl360.com/generic/downloads/RS32-Frequently-Asked-Questions.pdf)では、ファンドの売買とスイッチはいつでも無料とされています。一方、他社や他の商品では、年間の無料回数が決まっていたり、手数料がかかったりする場合があります。

また、スイッチ自体が無料でも、ファンドの側で次のような費用がかかることがあります。

- ファンドの運用管理費用（保有している間ずっとかかる）
- 一部のファンドの成功報酬
- 通貨の異なるファンドを買うときの為替の影響

スイッチ先のファンドの費用は、ファンドの資料（ファクトシート）で確認できます。見るべき数字は[ファンド選びで確認したい3つの数字](/blog/how-to-choose-funds)で解説しています。

## スイッチのときに気をつけたいことは？

1. **取引日のずれ**：売却と購入の取引日がずれると、その間は相場の動きの影響を受けたり、資金がファンドに入っていない状態になったりします。
2. **取引が停止しているファンド**：清算中や取引停止中のファンドは、売却できないことがあります（[ファンドが清算・停止中のとき](/blog/suspended-fund)）。
3. **相場を見たスイッチの繰り返し**：下がった後に売り、上がった後に買い戻すと、結果として高く買って安く売る形になりやすくなります。スイッチは、相場の予想ではなく、事前に決めた配分の考え方に沿って行うのが一般的です。
4. **運用権限の確認**：IFAや運用会社に運用の権限を渡している契約では、その権限の扱いも確認が必要です。

## 担当のIFAがいなくても、スイッチはできるの？

多くの場合、できます。契約者は保険会社と直接契約しているため、本人の署名がある依頼書やオンラインの操作で手続きできるのが一般的です。オンライン画面の登録方法が分からない場合は、保険会社の窓口に問い合わせましょう。

## スイッチの前後に、記録しておきたいことは？

スイッチをするときは、前後の状態を記録しておくと、後で結果を確認したり、問い合わせたりするときに役立ちます。

| 記録すること | 方法の例 |
| --- | --- |
| スイッチ前の保有内容 | 評価書や画面の保存（ファンド名、口数、評価額、割合） |
| 依頼した内容 | 提出した書類の写し、オンライン画面の確認画面の保存 |
| 依頼した日と取引日 | 受付の通知、取引完了の通知 |
| スイッチ後の保有内容 | 次の評価書で、指定どおりになっているかを確認 |
| スイッチの理由 | 「年1回の見直しで、決めた割合に戻すため」など、短いメモ |

最後の「理由」の記録は意外と大切です。理由を書こうとすると、相場の動きに反応しているだけなのか、決めたルールに沿っているのかが自分でも分かります。後で振り返ったときに、判断の良し悪しを相場の結果だけで評価せずに済むという利点もあります。

もし指定と違う内容で取引されていた場合は、記録を添えて早めに保険会社へ問い合わせましょう。時間がたつほど、確認に手間がかかりやすくなります。

## まとめ

ファンドの変更は、保険会社のオンライン画面か所定の書類で行うのが一般的で、契約者自身でも手続きできることが多くあります。「今ある口数のスイッチ」と「今後の積立金の配分変更」は別の手続きなので、両方の扱いを決めることが大切です。手数料や取引日は商品ごとに違うため、契約条件書で確認しましょう。今の保有ファンドを一覧で整理したい方は[AIチャット](/chat)を、配分について個別に相談したい方は[お問い合わせ](/contact)から提携先のアドバイザーをご紹介できます。
