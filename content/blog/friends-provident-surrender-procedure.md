「フレンズプロビデントの解約を考えているけれど、どこに何を出せばいいのかわからない」。担当のIFA（保険会社の商品を販売し、契約の窓口になる独立系の担当者）と連絡が取れず、手続きの入口で止まってしまう方は少なくありません。結論から言うと、解約は決められた書式に契約者全員が署名し、本人確認の書類とあわせて保険会社の問い合わせ窓口（カスタマーサービス）に送るのが基本の流れです。この記事では、その手順を公式の資料に沿って整理します。解約していくら戻るかは[フレンズプロビデントの解約返戻金はいくら？](/blog/friends-surrender-value)で解説しているので、あわせてご覧ください。

## フレンズプロビデントは今どんな会社なの？

フレンズプロビデント・インターナショナル（FPI）は、マン島に本拠を置く生命保険会社で、現在は同じマン島の保険会社RL360と同じインターナショナル・ファイナンシャル・グループ（IFGL）に属しています。アビバからIFGLへの売却は2020年に完了しました（[Aviva](https://www.aviva.com/newsroom/news-releases/2020/07/aviva-completes-the-sale-of-fpil/)）。その後、2023年1月には、投資会社のシンヴェン（Cinven）がIFGLの筆頭投資家になったと発表されています（[FPI](https://advisers.fpinternational.com/news/company-news-releases/cinven-becomes-new-ifgl-majority-investor.htm)）。この発表では、契約者の契約内容が変わるという説明はありませんでした。会社の経緯は[フレンズプロビデント（FPI）ってどんな会社？](/blog/what-is-friends-provident)にまとめています。

## 解約はどんな流れで進むの？

決められた書式を記入し、署名と必要書類をそろえて送り、保険会社の確認を経て送金される流れです。

| 手順 | 内容 |
| --- | --- |
| 1. 金額の確認 | 解約返戻金（解約したときに戻ってくるお金）の見積もり（surrender quotation）を取り、差し引かれる額を確認する |
| 2. 書式の入手 | 公式サイトの[書類ライブラリ](https://www.fpinternational.com/knowledge/document-library/)から「Request for payment by withdrawal or surrender」を入手する |
| 3. 記入と署名 | 「Full surrender of policy（全部解約）」を選び、契約者全員が署名する |
| 4. 書類の添付 | 本人確認・住所証明、必要に応じて銀行明細のコピーをつける |
| 5. 送付 | メールまたは郵送でカスタマーサービスに送る |
| 6. 確認・送金 | 電話での本人確認がある場合もあり、支払いが済むと通知が届く |

書式の[最新版（SERV07b 09/25）](https://www.fpinternational.com/documents/SERV07-Withdrawal-surrender-row.pdf)では、送り先としてメール（customerservices@fpiom.com）と、マン島の住所（Royal Court, Castletown, Isle of Man, IM9 1RA）が案内されています。最新の連絡先は[お問い合わせページ](https://www.fpinternational.com/contact-us/index.htm)でも確認できます。

## 書式には何を書くの？

契約者の情報、解約の種類、受取通貨、送金先の口座、署名が主な記入項目です。英語の書式で、すべて大文字（ブロック体）での記入を求められています。

| 項目 | 主な内容 |
| --- | --- |
| 契約者の情報 | 証券番号（保険契約の番号）、氏名、住所、電話番号、メール、職業 |
| 解約の種類 | 全部解約か、一部の証券（セグメント）の解約か |
| 解約控除の確認 | 解約控除（早く解約したときに差し引かれる費用）がかかることを理解したうえで進める、という確認欄 |
| 受取通貨 | 通貨を「USD」のような記号で記入 |
| 送金先 | 銀行名、口座名義、口座番号、SWIFTコード（銀行を国際的に見分けるための番号）、中継銀行（送金の途中で経由する銀行。必要な場合） |
| 税務情報 | 税務上の居住国と納税者番号（TIN。日本ではマイナンバー）、米国人に当たるかどうか |
| 署名 | 契約者全員の署名と日付 |

書式には、全部解約を申し込んだ後は一部引き出しができないことも書かれています。解約の理由を選ぶ欄もあります。税務情報の書き方がわからない場合は、[CRSの記事](/blog/crs-explained)も参考にしながら、カスタマーサービスに確認してください。

## 本人確認の書類はどう用意するの？

認証（原本と同じだと専門家に証明してもらうこと）を受けた身分証明書のコピーと、住所を証明する書類が必要です。FPIの[本人確認・住所証明のガイドライン](https://www.fpinternational.com/documents/id01-id-and-address-verification-guidelines-individuals.pdf)では、次のように案内されています。

- 身分証明：写真と署名がはっきり写ったパスポート、国の身分証明書、運転免許証のいずれかの認証付きコピー
- 住所証明：発行から6か月以内の銀行明細や公共料金の請求書など（携帯電話の請求書は不可）
- 認証できる人：公証人、弁護士、会計士、大使館・領事館の職員など
- 自己認証：書類を持った本人の写真と、書類そのものの写真を、登録済みのメールアドレスから送る方法もある

書類の準備のコツは[本人確認（KYC）書類の出し方](/blog/kyc-documents)で解説しています。住所が登録時から変わっている場合は、[住所変更の手続き](/blog/change-of-address)も確認しておくと手続きが進みやすくなります。

## 署名や送り方で気をつけることは？

署名は契約者全員分が必要で、貼り付けた署名は受け付けられません。最新の書式では、手書きの署名か、DocuSignやAdobe Signなど指定の電子署名サービス（いつ誰が署名したかの記録が残るもの）が使えるとされています。

スキャンしたコピーでの提出は可能で、原本の郵送は原則不要と書かれています。ただし、保険会社が原本を求めることがあるため、原本は保管しておきましょう。証券の原本については[証券原本の保管と再発行](/blog/friends-policy-document)をご覧ください。

メールで送るときは、件名に証券番号を入れておくと照合が早くなります。件名の書き方には決まりがある場合があるため、FPIの[問い合わせガイド](https://www.fpinternational.com/documents/corp003-contacting-fpi.pdf)で確認してください。同じガイドには、オンラインの契約者ページ（FPI Portal）から解約の申し込みができるとも書かれていますが、ご自身の契約で使えるかはPortalやカスタマーサービスで確認してください。

## 解約金はどの通貨で、どこに振り込まれるの？

毎月払いの積み立てプランは、契約の通貨で支払われると書式に記載されています。支払い方法は海外への電信送金（TT）と、英国内のポンド口座向けのBACS（英国内の銀行振込の仕組み）で、銀行手数料は契約者の負担です。

初めて使う口座に振り込む場合は、銀行明細のコピーが必要です。居住国と口座のある国が違う場合は、その理由の説明も求められます。日本の銀行で外貨の送金を受け取る場合は、外貨のまま受け取れるか、円に換えるときの手数料はいくらかを、事前に銀行に確認しておくと安心です。

支払いまでの日数の目安は、積み立てプランについての公式資料では確認できませんでした。書類の不備があると処理が遅れると書かれているので、提出前にチェックリストを見直しておきましょう。

## まとめ

フレンズプロビデントの解約は、決められた書式に契約者全員が署名し、本人確認・住所証明などとあわせてカスタマーサービスに送るのが基本です。書式や必要書類は時期によって変わるため、最新のものはフレンズプロビデントのカスタマーサービスで確認してください。解約前に確認したい点は[解約の前に確認しておきたい5つのこと](/blog/before-surrender)、税金は[解約したときの確定申告の考え方](/blog/tax-on-surrender)で解説しています。書類の整理には[AIチャット](/chat)、個別の相談は[お問い合わせ](/contact)をご利用ください。
