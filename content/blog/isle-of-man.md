契約書類に「Isle of Man」と書いてあるけれど、どこにあるのか、どんな場所なのか分からない。そんな方は多いと思います。結論から言うと、マン島はイギリスとアイルランドの間にある、独自の法律を持つ自治領です。生命保険会社を監督する当局と、保険会社が破綻したときの補償制度があることが、国際的な保険会社が拠点を置く理由の一つになっています。

## マン島はどこにあるのですか？

マン島（Isle of Man）は、イギリスのグレートブリテン島とアイルランド島の間、アイリッシュ海に浮かぶ島です。

面積は日本の淡路島とほぼ同じくらいの小さな島ですが、長い自治の歴史を持ち、オートバイの公道レースでも知られています。

## マン島はイギリスの一部ですか？

いいえ、イギリスの一部ではありません。

マン島政府によると、マン島はイギリスの一部であったことはなく、独自の議会・政府・法律を持つ自治の英国王室属領（クラウン・ディペンデンシー）です（[マン島政府](https://gov.im/about-the-government/departments/cabinet-office/external-relations/constitution)）。英仏海峡にあるジャージー島、ガーンジー島も同じ立場です。国際関係と防衛については、イギリスが責任を負っています。

| 項目 | マン島 |
| --- | --- |
| 位置 | イギリスとアイルランドの間、アイリッシュ海 |
| 法的な立場 | 英国王室属領（イギリスの一部ではない） |
| 議会・法律 | 独自の議会と法律を持つ |
| 外交・防衛 | イギリスが責任を負う |
| 金融の監督当局 | マン島金融サービス庁（IOMFSA） |

## なぜ海外積み立ての保険会社がマン島にあるのですか？

規制と契約者保護の仕組みが整った国際金融センターとして、長く発展してきたからです。

マン島には、生命保険会社を監督するマン島金融サービス庁（IOMFSA：Isle of Man Financial Services Authority）があり、保険会社はその免許と監督のもとで事業を行います。日本人の契約者が多い会社では、[RL360](/blog/what-is-rl360)、[ハンサード](/blog/what-is-hansard)、[フレンズプロビデント・インターナショナル](/blog/what-is-friends-provident)などがマン島に拠点を置いています。

税制が企業にとって有利であることも理由の一つとして挙げられますが、日本の居住者にとって節税になるわけではありません。日本の居住者は、国内外の所得が日本で課税対象です。詳しくは[オフショアとタックスヘイブンの違いの記事](/blog/offshore-vs-tax-haven)をご覧ください。

## マン島の投資家保護制度とはどんなものですか？

マン島には、生命保険会社が破綻した場合に、契約者に補償金を支払う法律上の制度があります。

この制度は「契約者補償制度（Policyholders' Compensation Scheme）」と呼ばれ、1991年の規則（Life Assurance (Compensation of Policyholders) Regulations 1991）にもとづいています。マン島金融サービス庁は、次のように説明しています（[IOMFSA](https://www.iomfsa.im/consumer-material/compensation-scheme-life-assurance)）。

| 項目 | 内容 |
| --- | --- |
| 補償の上限 | 保護対象となる契約の価値の最大90% |
| 対象 | マン島で長期保険事業を行う保険会社の契約 |
| 財源 | マン島で事業を行う生命保険会社からの拠出 |
| 支払いの時期 | 期限はなく、全額の支払いまでに数年かかることがある |
| 対象外の例 | もともとマン島以外の保険会社が引き受け、後からマン島の会社に移された契約 |

つまり、万一保険会社が破綻しても、すべてを失うわけではない仕組みが法律で用意されています。

## 補償制度があれば、絶対に安全ですか？

いいえ。補償制度は大切な安全網ですが、限界もあります。

まず、補償は契約価値の最大90%で、全額ではありません。また、支払いまでに数年かかることがあると当局自身が説明しています。さらに、この制度が守るのは保険会社の破綻に対してであり、運用しているファンドの値下がりは対象外です。ファンドが下がって評価額が減っても、それは補償の対象ではありません。

| リスク | 補償制度で守られるか |
| --- | --- |
| 保険会社の破綻 | 条件を満たせば、最大90%まで補償 |
| ファンドの値下がり | 守られない |
| 為替による円換算額の減少 | 守られない |
| ファンドの取引停止 | 原則として対象外 |

保険会社の破綻時の考え方は、[保険会社の破綻と保護の記事](/blog/provider-insolvency-protection)で詳しく比較しています。

## 日本に住んでいる人とマン島の保険会社の関係は？

マン島の保険会社の多くは、日本で保険業の免許を持っていません。

日本に支店等を設けていない外国保険会社が日本居住者と保険契約を結ぶことは、[保険業法第186条](https://www.fsa.go.jp/news/r6/hoken/20241017/20241017.html)で原則として禁止されています。すでに契約している方は、契約内容と手続きの方法を正しく把握しておくことが大切です。

## まとめ

マン島は、イギリスとアイルランドの間にある、独自の法律を持つ英国王室属領です。生命保険会社を監督する当局と、破綻時に契約価値の最大90%を補償する制度があることが、保険会社が拠点を置く理由の一つです。ただし、補償は全額ではなく、ファンドの値下がりは対象外である点も押さえておきましょう。契約内容の整理には[AIチャット](/chat)が使えます。不明点は[お問い合わせ](/contact)からご相談ください。
