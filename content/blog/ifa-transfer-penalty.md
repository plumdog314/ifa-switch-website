「今のIFAに不満があるけれど、変えたら違約金を取られるのでは」「契約が途切れてしまうのでは」。こうした心配から、連絡の取れないIFAのまま我慢している方もいます。結論から言うと、IFAを変えても保険会社との契約はそのまま続くのが一般的で、変更を理由に保険会社から違約金を求められる仕組みにはなっていません。ただし、いくつか確認しておきたい例外があります。

## IFAを変えると、契約はどうなるの？

契約はそのまま続きます。IFAの変更とは、保険会社の記録上の「担当代理店（Servicing Agent）」を別の会社に替える手続きです。

変わるものと変わらないものを整理すると、次のとおりです。

| 項目 | IFAを変更すると |
| --- | --- |
| 証券番号（Policy Number） | 変わらない |
| 積み立ての残高・評価額 | 変わらない |
| 運用中のファンド | 変わらない（変更する場合は別の手続き） |
| 毎月の積立額・支払方法 | 変わらない |
| 契約期間・初期口座（イニシャルユニット：最初の期間に払った分。手数料が重い）の期間 | 変わらない |
| 問い合わせ・相談の窓口 | 新しいIFAになる |
| IFAが見られる契約情報 | 新しいIFAが見られるようになる |

つまり、IFAの変更は「契約の作り直し」ではなく「担当者の交代」です。手続きの流れは[IFAを変更（移管）する手続きと流れ](/blog/how-to-change-ifa)で詳しく説明しています。

## 違約金がかかることはないの？

保険会社との契約の上では、IFAの変更を理由に違約金がかかる仕組みは一般的ではありません。海外の積み立てプランの費用は、主に初期口座の手数料や管理費用として契約に組み込まれており、担当者が誰であるかによって変わるものではないからです。

一方で、次のような費用は別に考える必要があります。

- **IFAと直接結んでいる顧問契約の費用**：助言の手数料（アドバイザリーフィー）などをIFAに払っている場合、その契約の解約条件はIFAとの契約書で決まります。
- **新しいIFAの費用**：新しいIFAがアドバイザリーフィーを設定している場合は、その金額と内容を確認します。
- **解約して入り直す場合の費用**：IFAの変更ではなく「新しいプランへの乗り換え」を提案された場合は、解約控除（早く解約したときに差し引かれる費用）と新しい契約の初期費用の両方がかかることがあります。

「IFAを変えるには一度解約が必要」と言われた場合は、本当にそうなのかを保険会社に直接確認してください。通常のIFA変更では解約は不要です。

## IFAを変えられないことはある？

あります。主な例は次のとおりです。

| 例外の場合 | 内容 |
| --- | --- |
| 新しいIFAが代理店登録をしていない | 新しいIFAがその保険会社と代理店契約を結んでいなければ、担当として登録できない |
| 保険会社が新規の代理店登録を制限している | 地域や商品によって、受け入れる代理店を限っていることがある |
| 契約が信託や法人名義になっている | 受託者（信託の財産を管理する人）や法人の代表者など、本人以外の署名が必要になる |
| 書類の不備・本人確認が終わっていない | 住所証明などの提出が求められ、終わるまで手続きが止まることがある |

初期口座期間中かどうかによって扱いが変わるかについては、[初期口座期間中でもIFAは変更できる？](/blog/change-ifa-during-initial-period)で解説しています。

## 旧IFAに知らせなくてもいいの？

一般的には、契約者本人が署名した変更依頼書を保険会社に提出すれば、旧IFAの同意がなくても手続きが進みます。保険会社は、契約者本人の意思を確認できれば変更を受け付けることが多いからです。

ただし、旧IFAとの間で顧問契約などを結んでいる場合は、その契約の解約の連絡は別に必要になることがあります。感情的なやり取りを避けたい場合は、事務的に「担当を変更しました」と伝えるだけでも十分です。

## 「違約金がかかる」と言われたら、どう確かめる？

保険会社に直接、書面かメールで質問するのが確実です。IFAの説明と保険会社の説明が違う場合は、契約の当事者である保険会社の回答が基準になります。

問い合わせの例は次のとおりです。

- 証券番号と契約者の氏名・生年月日を書く
- 「担当代理店（Servicing Agent）を変更した場合、契約者に費用や違約金は発生しますか」と聞く
- 「変更に必要な書類と手順を教えてください」と添える

回答はメールで受け取り、保存しておきましょう。後から説明が食い違ったときの記録になります。英語でのやり取りに不安がある場合は、翻訳ツールを使って短い文で書けば十分伝わります。

## 変更する前に何を確認すればいい？

次の4点を確認しておくと、後から「こんなはずではなかった」となりにくくなります。

1. 新しいIFAがその保険会社に代理店登録しているか
2. 新しいIFAのライセンス（香港なら、香港の保険業監管局（IA）や香港の証券先物委員会（SFC）などの登録）
3. 新しいIFAの費用と、どこまで対応してくれるか
4. 旧IFAと結んでいる契約があるか、その解約条件

IFAのライセンスの確認方法は[IFAが本物か確認する方法：SFC・IAのライセンス検索](/blog/verify-ifa-license)をご覧ください。

## まとめ

IFAを変えても、保険会社との契約はそのまま続くのが一般的です。変更を理由に保険会社から違約金を求められる仕組みにはなっていません。確認が必要なのは、新しいIFAが代理店登録をしているか、旧IFAと別の契約を結んでいないか、そして「解約して入り直す」話になっていないかの3点です。

IFAの変更を考えている方は、[お問い合わせ](/contact)からご相談ください。IFAスイッチでは、ライセンスを持つ提携アドバイザーのご紹介や、手続きの流れのご案内ができます。
