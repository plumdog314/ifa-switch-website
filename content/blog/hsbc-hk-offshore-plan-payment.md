海外積み立て（RL360、Hansard、Friends Provident、Investors Trustなど）の保険料を、香港HSBCの口座から払っている方は多くいます。結論から言うと、気をつけたいのは「手数料」「残高不足」「通貨」「限度額とカードの期限」の4つです。HSBC側の設定がうまくいかないと、保険料が払われないまま気づかないこともあります。

この記事では、HSBCの[個人向け手数料表（2026年11月1日適用）](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/ways-to-bank/bank-tariff/20261101-guide.pdf)と[送金・支払いのFAQ](https://www.hsbc.com.hk/help/faq/transfers-and-payments/)をもとに、事実を整理します。支払い方法の変更を勧めるものではありません。

## 香港HSBCから保険料を払う方法には、何がある？

主に「定期送金」「その都度の送金」「autoPay（直接引き落とし）」「カード払い」があります。どれが使えるかは、保険会社が受け付ける方法によって決まります。

| 方法 | しくみ |
| --- | --- |
| 定期送金（スタンディング・インストラクション） | 決めた日に、決めた金額を、決まった間隔で送金するよう銀行に頼んでおく |
| その都度の送金 | 支払いのたびに、自分で電信送金（TT）の手続きをする |
| autoPay（直接引き落とし） | 受取側に、口座から定期的に引き落とす権限を渡す |
| カード払い | 保険会社にカード情報を届け、カードから引き落としてもらう |

FAQでは、定期送金は「決まった金額を決まった間隔で送る」もの、autoPayは「指定した受取人が口座から定期的に引き落とす」ものと説明されています。autoPayはHSBCの手数料表で「direct debit authorisation（直接引き落としの授権）」とも呼ばれます。海外の保険会社がHSBCのautoPayで保険料を集めているかは、公式資料では確認できませんでした。

なお、FAQによると、2026年10月2日から電話バンキングでの電信送金の受付は終わりました。今はアプリ、オンラインバンキング、支店、書面の郵送で手続きします。

## 定期送金の手数料は、いくらかかるの？

設定はオンラインなら無料ですが、海外への定期送金は、実行されるたびに1回分の電信送金手数料がかかります。

[手数料表](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/ways-to-bank/bank-tariff/20261101-guide.pdf)で確認できた主な金額は次のとおりです（本記事の確認時点（2026年11月））。

| 項目 | 金額 |
| --- | --- |
| 定期送金の設定・変更（オンライン・アプリ） | 無料 |
| 定期送金の設定・変更（支店） | HK$70（65歳以上などは無料） |
| オンラインでの海外送金（HSBC以外の銀行あて） | 1回HK$70（一部の口座区分は、条件を満たせば無料） |
| 海外のHSBCが中継・受取銀行として取る手数料 | オンラインはHK$100（一部の上位の口座区分は無料） |
| 送金の変更・問い合わせ・取消・返金（返戻） | HK$275＋海外の銀行の手数料 |

手数料表の注記には、定期送金による電信送金は、オンラインでの1回の電信送金と同じ手数料がかかると書かれています。また、海外のHSBC口座あての送金が無料になる扱いは、定期送金で設定した送金には使えず、毎回HK$70かかるとされています。これとは別に、途中の銀行や受取銀行が手数料を差し引くことがあります。

設定内容は、あとから直接書き換えることはできません。FAQでは、アプリの「Manage future payments」などで古い指示を消し、新しく作り直す方法が案内されています。変えずに直したい場合は、書面、支店、アプリの「Chat with us」、電話でも受け付けるとされています。電話番号は、Premier Eliteの方が (852) 2233 3033、Premierの方が (852) 2233 3322、それ以外の方が (852) 2233 3000 です。

また、FAQによると、2026年8月から一部の送金で、受取人や銀行の住所に国と都市の記載が必要になりました。記載がないと、予約や定期の送金が断られ、最終的に指示が取り消されることがあるとされています。

## 支払日に残高が足りないと、どうなるの？

海外送金は実行されません。HSBCから通知は来ますが、保険会社への支払いは止まったままになります。

| 場面 | HSBCの扱い |
| --- | --- |
| 海外送金 | 残高不足になる指示は実行しない（手数料表） |
| 予約していた送金 | 送金されず、アプリやオンラインバンキングのメッセージで知らせる（FAQ） |
| 定期送金の失敗 | 失敗したら通知を送る（FAQ） |
| autoPay | 残高不足で戻ると1件HK$180（手数料表） |

手数料表の注記では、定期送金やautoPayで口座が残高不足になる場合、HSBCは臨時の借り越し（当座貸越）の依頼とみなし、応じるか断るかを決めるとされています。応じた場合は利息と、Premierなどは1回HK$100、ほかの多くの口座は1回HK$120の手数料がかかります。

[autoPayの申込書](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/transfer-payments/direct-debit-authorisation-generic-setup.pdf)には、引き落とし日の前の営業日（支店の営業時間内）までにお金を入れておくこと、30か月続けて引き落としがないと銀行が取り消せることが書かれています。

## 通貨は、どう考えればいいの？

保険料と同じ通貨の残高から送ると、両替が入りません。違う通貨の口座から送る場合は、HSBCの為替レートで両替されます。

FAQでは、電信送金は送る側と受け取る側の口座が対応している通貨なら使え、両替をともなう送金もできるとされています。たとえば米ドル建ての保険料を香港ドルの残高から送ると、送金のたびに両替が入ります。

カード払いの場合、[手数料表](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/ways-to-bank/bank-tariff/20261101-guide.pdf)では、香港ドル建ての多くのクレジットカードで、香港ドル以外の取引に1.95%の手数料がかかるとされています（カードの種類で異なります）。HSBC Mastercardデビットカードは、この手数料が無料で、外貨の残高が足りなければ香港ドルから両替されると書かれています。

## 限度額やカードの期限で、気をつけることは？

海外送金には1日の限度額があり、初めは0香港ドルに設定されています。カード払いでは、カードの更新や利用枠も確認が必要です。

FAQによると、海外への送金にかかる「1日の国際送金の上限（daily cross-border transfer master limit）」は、初めはHKD0で、最大HKD3,000,000まで、アプリやオンラインバンキングで変えられます。autoPayでは、請求額が自分で決めた上限額を超えると、引き落とされないとされています。

カード払いでは、手数料表で、利用残高が利用枠を超えたときに手数料（多くのカードでHK$90）がかかるとされています。カードが新しくなって番号や有効期限が変わったときは、保険会社への届け出が必要です。くわしくは[クレジットカードが更新されたら？](/blog/update-credit-card)をご覧ください。

## 保険会社の側では、何が起きるの？

支払いが止まったときの扱いは、保険会社と商品の規定で決まります。HSBC側の通知だけでは、契約にどう影響するかは分かりません。

支払いが遅れると、まとめての支払いを求められたり、再開のときに引き落としが重なったりすることがあります。[停止していた積み立てを再開したら「まとめて払え」と言われた](/blog/lump-payment-after-pause)や、[カード引き落としが止まった後、二重払いになったときの対処](/blog/double-payment)もあわせてご覧ください。正確な扱いは、加入している保険会社の約款や案内で確認してください。

## まとめ

香港HSBCから海外積み立ての保険料を払うときは、手数料、残高不足、通貨、限度額とカードの期限の4つを確認しておくと安心です。海外への定期送金は、実行のたびに1回分の送金手数料がかかります。残高が足りないと送金されず、autoPayなら残高不足で1件HK$180かかります。支払いが止まったときの契約への影響は、保険会社の規定で決まります。HSBCの手数料全体は[香港HSBCの手数料と最低残高](/blog/hsbc-hk-fees-minimum-balance)、ログインできないときは[香港HSBCにログインできないときは？](/blog/hsbc-hk-cannot-login)で整理しています。
