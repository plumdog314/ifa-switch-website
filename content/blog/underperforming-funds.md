「積み立てを続けているのに、このファンドだけ全然増えない」と感じていませんか。結論から言うと、成績が悪いかどうかは、正しい比較相手と比べて初めて分かります。比べ方を間違えると、よいファンドを手放したり、悪いファンドを持ち続けたりしやすくなります。

## 「成績が悪い」はどうやって判断すればいいですか？

同じ種類の指数（ベンチマーク）や同種ファンドと、同じ条件で比べて判断します。日本株ファンドを米国株の指数と比べても、意味のある比較にはなりません。

比べるときにそろえる条件は、次の4つです。

| そろえる条件 | 理由 |
| --- | --- |
| 資産クラス・地域 | 新興国株と先進国債券は、値動きの性質がまったく違う |
| 期間 | 1年だけでは偶然の影響が大きい |
| 通貨 | ドル建てと円換算では、為替で数字が大きく変わる |
| 手数料控除後か | 実際に受け取れるのは手数料を引いた後のリターン |

たとえばファンドが1年で5％下がっても、同じ地域の指数が10％下がっていたなら、相対的には健闘したことになります。逆に、指数が20％上がった年に10％しか上がらなかったなら、上昇していても劣後しています。

## 1年成績が悪いだけで替えるのは早いですか？

1年だけの不振で判断するのは早いことが多いです。市場には、ある投資スタイル（成長株、割安株など）が数年単位で不調になる時期があり、短期の順位は入れ替わりやすいからです。

米国の調査でも、上位の成績を何年も続けられるファンドはごく一部にとどまることが繰り返し示されています（[S&P Dow Jones Indices：SPIVA](https://www.spglobal.com/spdji/en/spiva/article/spiva-us-year-end-2024)）。短期の順位で乗り換えを繰り返すと、上がった後に買い、下がった後に売る結果になりやすい点に注意が必要です。詳しくは[過去リターンに飛びついてはいけない理由](/blog/chasing-past-returns)で解説しています。

## 見直しを検討する一般的なサインは何ですか？

一般的には、次のようなサインが重なったときに、見直しを検討する人が多いです。

1. **3〜5年以上、ベンチマークや同種ファンドを継続して下回っている**
2. **運用方針や運用担当者が変わった**（以前の成績が参考にならなくなる）
3. **コストが同種ファンドより明らかに高い**（長期では差が積み重なります。[手数料が25年で効く理由](/blog/cost-matters)参照）
4. **運用資産が大きく減っている、または取引停止の通知が来た**
5. **自分の目的とずれてきた**（満期が近いのに値動きの大きい資産に集中しているなど）

反対に、「市場全体が下がった」「一時的に順位が落ちた」だけであれば、見直しの理由としては弱いと考えられます。

## 替える場合、何を確認すればいいですか？

替えるかどうかはご本人の判断ですが、判断の前に次の点を確認しておくと、後悔を減らせます。

- 乗り換え先候補も、同じ条件（期間・通貨・手数料控除後）で比べたか
- 乗り換え先の過去成績が、たまたま好調な時期だけを見たものではないか
- プラン内のスイッチ手数料や回数制限はどうなっているか
- 全体の資産配分（株と債券の割合、地域の偏り）がどう変わるか

スイッチの具体的な手順は[ファンドの変更方法](/blog/how-to-switch-funds)をご覧ください。手元のファンドを一覧にして比べたいときは、[AIチャット](/chat)で保有状況を整理することもできます。

## 比べた結果を、どう記録しておけばいいですか？

比べた結果は、簡単な表にして残しておくと、次回の見直しで役立ちます。毎回ゼロから調べ直すより、同じ物差しで変化を追えるからです。

| 記録する項目 | 記入の例 |
| --- | --- |
| ファンド名と通貨 | 世界株ファンド（米ドル建て） |
| 比較対象の指数 | 全世界株式の指数 |
| 1年・3年・5年のリターン | ファンドと指数をそれぞれ記入 |
| 経費率 | ファクトシートに記載の数字 |
| 気づいた変化 | 運用担当者の交代、方針の変更など |

この表を年に1回ほど更新すると、「一時的な不振」なのか「継続的な劣後」なのかが見えやすくなります。たとえば、3年続けて指数を大きく下回り、その間に運用担当者も替わっていたなら、見直しを検討する材料がそろってきたと言えます。逆に、1年だけ下回って翌年に追いついているなら、短期の揺れの範囲と考える人が多いでしょう。

大切なのは、数字を感情ではなく同じ基準で見ることです。値下がりした直後は、どのファンドも悪く見えがちです。記録があれば、そのときの気分ではなく、事実に基づいて判断しやすくなります。

## まとめ

- 成績の良し悪しは、同じ種類の指数と同じ条件で比べて判断します。
- 1年の不振より、数年単位の継続的な劣後や運用体制の変化が重要なサインです。
- 替えるかどうかは、コストや資産配分も含めて本人が判断します。
