「もしものときに家族がきちんと受け取れるよう、受取人を決めておきたい」。そう考えても、英語の書類や海外の手続きに戸惑う方は多いと思います。結論から言うと、海外積み立ての受取人は、保険会社が決めた書類に受取人の情報を書き、契約者が署名して提出するのが一般的です。ただし、受取人を直接指定できない契約もあるため、まず自分の契約の仕組みを確認することが出発点です。

## 海外積み立てでは受取人を指定できる？

契約によって違います。主に次の3つの型があります。

| 型 | 内容 |
| --- | --- |
| 受取人を指定できる | 保険会社が決めた書類で受取人（Beneficiary）を決められる |
| 信託（トラスト）で決める | 契約を信託に入れ、信託の受益者として家族を決める |
| 指定の仕組みがない | 死亡給付は契約者の遺産として扱われ、相続手続きを経て支払われる |

信託（トラスト）とは、財産を信頼できる人（受託者）に預け、決めた人（受益者）のために管理してもらう仕組みです。英国の法律の考え方を使う国や地域の保険会社では、信託用の書式を用意していることがあります。どれが使えるかは、保険会社に「受取人を指定する方法を教えてほしい」と問い合わせるのが確実です。

## 指定・変更の手続きはどう進める？

一般的な流れは次のとおりです。

1. 保険会社に、受取人の指定（または変更）用の書式を請求する
2. 受取人の情報を記入する
3. 契約者が署名する（被保険者や共同契約者の署名が必要な場合もある）
4. 必要に応じて本人確認書類を添えて提出する
5. 保険会社からの受付確認を受け取り、保管する

5番目は特に大切です。書類を出しただけで、反映されたかどうか確かめていない場合は少なくありません。受付の確認書が届かないときは、問い合わせましょう。英文の問い合わせのコツは[保険会社への連絡のコツ](/blog/provider-not-responding)で紹介しています。

## どんな個人情報が必要？

受取人について求められやすい情報は次のとおりです。

| 情報 | 注意点 |
| --- | --- |
| 氏名（ローマ字） | パスポートと同じ綴りにする |
| 生年月日 | 日・月・年の順番に注意（英国式は日/月/年） |
| 契約者との続柄 | 配偶者、子など |
| 住所 | 英語の住所の書き方は[住所変更の記事](/blog/change-of-address)を参照 |
| 受け取る割合 | 複数人の場合、合計100%になるように書く |

複数人を指定する場合、誰かが先に亡くなっていたときの扱いも書式で決められることがあります。

## マイナンバーは必要？

海外の保険会社への受取人指定と、マイナンバーは分けて考えるのが分かりやすいです。マイナンバーは日本の税や社会保障の手続きのための番号で、海外の保険会社が受取人指定で求めるのは、上の表のような情報が一般的です。ただし書式は会社ごとに違うため、最新の書類を確認してください。

一方で、日本国内では別の場面でマイナンバーが必要になることがあります。たとえば、海外からの送金を日本の銀行で受け取るときは、国外送金等調書法（海外との送金を税務署に報告させる法律）にもとづき、マイナンバーを記載した告知書の提出を求められることがあります（[個人情報保護委員会のFAQ](https://www.ppc.go.jp/all_faq_index/faq5-q19-7)）。保険会社への届出状況とあわせて[海外積み立てとマイナンバーの記事](/blog/my-number-and-offshore)も参考にしてください。

## 受取人を決めるとき、税金で気をつけることは？

日本の居住者が受け取る場合、保険料を負担した人と受取人の組み合わせで税金が変わります。

- 満期保険金：保険料の負担者と受取人が同じなら所得税、違えば贈与税（[国税庁No.1755](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1755.htm)）
- 死亡保険金：亡くなった人が保険料を負担していれば、原則として相続税（[国税庁No.4114](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4114.htm)）

海外の契約に日本の非課税枠などがどう適用されるかは、契約内容によって判断が分かれることがあります。受取人を決める前に、税理士に相談しておくと安心です。

## 指定したあと、何を見直せばいい？

結婚、離婚、子どもの誕生、受取人の死亡など、家族の状況が変わったときは必ず見直しましょう。指定が古いままだと、意図しない人が受け取ることになりかねません。

契約者が亡くなったときの全体の流れは[契約者が亡くなったら海外積み立てはどうなる？](/blog/if-policyholder-dies)で解説しています。手続きで迷ったら[お問い合わせ](/contact)からご相談ください。

## 書類を出すとき、よくある不備は？

受取人の指定書類は、ちょっとした記入ミスで差し戻されることがあります。よくあるのは、署名が契約時と違う書き方になっている、受け取る割合の合計が100%にならない、受取人の名前の綴りがパスポートと違う、日付が空欄、といったものです。

提出する前に、コピーを取っておくことも大切です。書類が保険会社に届かなかった場合や、受付の内容に誤りがあった場合に、何を出したかを示せます。郵送の場合は、追跡できる方法を使うと安心です。

## まとめ

海外積み立ての受取人は、保険会社が決めた書類に受取人の情報を記入し、契約者が署名して提出するのが一般的です。指定できない契約や信託を使う契約もあるため、まず保険会社に方法を確認しましょう。マイナンバーは日本国内の受け取りや税務の場面で必要になることがあり、税金の扱いは税理士への確認が安心です。
