「自分の積み立てはRL360という会社のものらしいが、どんな会社なのかよく知らない」という方は少なくありません。担当者と連絡が取れなくなると、なおさら不安になります。結論から言うと、RL360はマン島に本社を置き、マン島の金融当局の認可を受けた生命保険会社です。ここでは、事実として確認できる範囲で、会社の姿を整理します。

## RL360はどこの国の会社なの？

RL360は、英国王室属領のマン島（イギリスとアイルランドの間にある島）に本社を置く保険会社です。RL360自身の資料には、正式名称が「RL360 Insurance Company Limited」で、登記上の本社がマン島ダグラスにあり、[マン島金融サービス庁の認可を受けている](https://www.rl360.com/generic/downloads/RS32-Frequently-Asked-Questions.pdf)と記載されています。

マン島はイギリスの一部ではなく、独自の法律と金融規制を持つ地域です。

## どんな経緯で今の会社になったの？

RL360の親会社グループであるIFGLの[公式サイトの沿革](https://ifg-ltd.com/about-us/our-history/)によると、主な流れは次のとおりです。

| 年 | 出来事 |
| --- | --- |
| 2004年 | 前身のスコティッシュ・ライフ・インターナショナルで新経営陣が成長戦略を開始 |
| 2007年 | 香港とドバイに拠点を開設 |
| 2009年 | 「ロイヤルロンドン360」のブランドを開始 |
| 2013年 | 経営陣が投資会社ヴィトルビアンの支援を受けて買収し、RL360に改称 |
| 2015年 | ロイズ・バンキング・グループからクレリカル・メディカル・インターナショナルを買収 |
| 2020年 | フレンズプロビデント・インターナショナルを買収 |
| 2023年 | 投資会社シンヴェンがIFGLの過半数を保有する投資家に |

つまりRL360は、かつて英国の相互会社ロイヤルロンドンのグループ会社でしたが、2013年以降は独立した会社グループとして運営されています。フレンズプロビデント・インターナショナルも、現在は同じグループに入っています。

## どの当局に規制されているの？

規制の中心はマン島金融サービス庁です。保険会社としての認可や監督は、本社のあるマン島の当局が行います。

一方、商品を販売したIFA（独立系ファイナンシャルアドバイザー）は、別の当局の規制を受けます。たとえば香港の保険仲介業者は、香港保険業監管局（Insurance Authority）の免許が必要です。保険会社と販売した仲介業者は別の会社であり、規制する当局も違うという点を押さえておくと、トラブルのときに問い合わせ先を整理しやすくなります。

## 主な商品は何？

日本人の保有者が多いのは、毎月積み立てる「クォンタム（Quantum）」です。RL360の[公式サイト](http://rl360.com/row/products/quantum/quantum.htm)によると、クォンタムは2019年7月1日に新規の申し込みの受付を終了しています。既存の契約者は、追加の払い込みやファンドのスイッチを引き続き行えます。

その後の積み立て商品としては「Regular Savings Plan」があり、手数料や初期口座の仕組みはクォンタムと異なります。このほか、一括で払い込む投資型の保険商品なども扱っています。クォンタムの仕組みは[RL360クォンタムの仕組み](/blog/rl360-quantum)でくわしく解説しています。

## 日本に住んでいる人とRL360の関係は？

RL360が日本に支店を置いているという情報は確認できません。日本の保険業法第186条では、日本に支店等を設けていない外国保険業者は、原則として日本の居住者と保険契約を結べないとされています（[金融庁の説明](https://www.fsa.go.jp/ordinary/densi/de_003.html)）。海外在住中に契約した、香港などに出向いて契約したなど、契約の経緯は人によって異なります。日本との法律上の関係は[海外積み立ては日本で契約できる？](/blog/can-japanese-residents-sign)で整理しています。

## RL360に問い合わせるときは、何を準備すればいいの？

担当のIFAと連絡が取れない場合でも、契約者はRL360に直接問い合わせることができます。やり取りは基本的に英語になるため、次の情報を手元にそろえておくとスムーズです。

| 準備するもの | 内容 |
| --- | --- |
| 契約番号 | 評価書や証券に記載されている番号 |
| 契約者の情報 | 氏名（パスポートと同じ表記）、生年月日、登録している住所 |
| 商品名 | クォンタム、Regular Savings Planなど |
| 問い合わせの内容 | 評価額の確認、解約返戻金の見積もり、住所変更など |
| 本人確認書類 | 手続きによってはパスポートの写しや住所証明を求められる |

RL360の書類には、契約の手続きに関する書類の送り先として、契約管理の窓口（servicing@rl360.com）が記載されています。手続きの種類によって窓口や必要書類が異なることがあるため、最新の案内はRL360の公式サイトで確認してください。

メールで問い合わせる場合は、件名に契約番号を書き、本文は短く要点だけにすると、返事をもらいやすくなります。連絡が取りにくいときのコツは[保険会社にメールしても返事が来ないときの連絡のコツ](/blog/provider-not-responding)で解説しています。
