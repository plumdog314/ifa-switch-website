「ハンサードのサイトにアクセスしても、ログインできない」「そもそもどこを見れば評価額がわかるのか」。紹介してくれたIFAと連絡が取れなくなり、自分で確認しようとして困っている方も多いと思います。結論から言うと、ハンサードの契約者は契約者用のオンライン口座で評価額などを確認でき、ログインには認証アプリが必要です。2026年3月21日からはSMSによる認証が使えなくなっているため、以前のやり方でログインできなくなった方もいます。

## オンライン口座では何ができるの？

契約の評価額、払込の状況、ファンドの情報を確認できます。ハンサードの[オンライン口座の案内ページ](https://www.hansard.com/clients/online-accounts/)では、契約の運用状況や評価額、払込の詳細をいつでも確認でき、ファンドの運用成績の情報も見られると説明されています。スマートフォンやタブレットにも対応しています。

| 確認できる主な情報 | 何に役立つか |
| --- | --- |
| 契約の評価額 | 今の資産の大きさを知る |
| 払込の状況 | 毎月の払い込みが正しく行われているかを確かめる |
| ファンドの情報 | どのファンドに入っていて、どう動いているかを知る |

画面の構成や細かい機能は変わることがあります。解約返戻金（解約したときに実際に戻る金額）は評価額とは違うため、正確な金額が必要な場合は、保険会社に見積もりを依頼してください。

## どこからログインするの？

契約者用とアドバイザー用で、ログインの入口が分かれています。ハンサードの公式サイト（[hansard.com](https://www.hansard.com)）から、契約者用（Client）のログインを選びます。アドバイザー用の入口では、契約者のIDではログインできません。

ブックマークする場合は、必ず公式サイトからたどったページを登録しましょう。検索結果の広告や、メールに書かれた見慣れないリンクから入るのは避けてください。

## はじめて登録するときの流れは？

公式サイトの案内では、次のような流れが示されています。

| 手順 | 内容 |
| --- | --- |
| 1. 登録リンクを受け取る | 保険会社から届く登録用のリンクを使う。届いていなければ契約者サポートに依頼する |
| 2. 認証アプリを用意する | Microsoft Authenticatorなどの認証アプリをスマートフォンに入れ、起動しておく |
| 3. 登録ページで手続きする | 途中でページを離れない。表示されるQRコードを飛ばさずに読み取る |
| 4. ログインを確かめる | パスワードと、認証アプリに表示される確認コードなどでログインする |

公式サイトでは、登録の前に認証アプリを起動しておくこと、登録中にページを離れないこと、QRコードを飛ばさないことが注意点として挙げられています。登録用の手引き（HG0130O）も公式サイトに掲載されています。

## ログインできないときは、どうすればいい？

原因によって対処が違います。よくある原因と対処を表にまとめます。

| よくある原因 | 対処 |
| --- | --- |
| 登録リンクが届いていない | 契約者サポートに登録リンクの送付を依頼する |
| 以前はSMSで認証していた | 2026年3月21日にSMSや電話での認証は終了。認証アプリでの再設定を依頼する |
| スマートフォンを買い替えた | 古い端末の認証アプリが使えなくなるため、認証の再設定を依頼する |
| パスワードを忘れた | ログイン画面のパスワード再設定の案内に沿う。できなければサポートに連絡 |
| 登録したメールアドレスが使えない | 住所・メールアドレスの変更手続きが必要になることがある |
| 何度も失敗してロックされた | 時間をおくか、サポートにロック解除を依頼する |

公式サイトでは、ブラウザを変える、別の端末を使うといった方法も案内されています。

## 問い合わせるとき、何を伝えればいい？

公式サイトでは、契約者向けの窓口として「ClientServicesSupport@hansard.com」が案内されています。問い合わせるときは、契約者本人の登録メールアドレスから、次の情報を英語で伝えるとスムーズです。

- 証券番号（Policy Number）
- 契約者の氏名（パスポートと同じ表記）と生年月日
- 登録している住所とメールアドレス
- 困っている内容（例：「登録リンクが届かない」「認証アプリを再設定したい」）

パスワードや認証アプリの確認コードは、メールに書かないでください。正規の窓口がそれを求めることは通常ありません。

住所やメールアドレスが変わっている場合は、先に変更の手続きが必要になることがあります。手続きの考え方は[住所が変わったときの海外積み立ての手続きと英語の住所の書き方](/blog/change-of-address)をご覧ください。

## オンライン口座を見るとき、どこに注目すればいい？

まずは、次の3つを確認する習慣をつけると安心です。

1. **払い込みが続いているか**：カードの更新などで、知らないうちに払い込みが止まっていないか
2. **どのファンドに入っているか**：知らないうちにファンドが閉鎖・統合されていないか
3. **評価額の推移**：毎日ではなく、月1回や四半期に1回など、決めた頻度で確認する

カードの更新で払い込みが止まった場合の手続きは、[クレジットカードが更新されたら：積み立ての支払い方法変更](/blog/update-credit-card)で解説しています。ハンサードという会社の基本は[ハンサードってどんな会社？](/blog/what-is-hansard)にまとめています。

ハンサードの契約者は、契約者用のオンライン口座で評価額や払込の状況を確認できます。2026年3月21日からはSMSによる認証が終了し、認証アプリが必要です。ログインできないときは、原因に合わせて契約者サポートに、証券番号などを添えて契約者本人から連絡しましょう。
