# ライトプラン会員ページを公開するまでの手順

会員ページ（/members）と、そこに載せる手続きガイド・英文レターのひな形はできています。
今は環境変数が未設定のため、会員ページは「準備中」の表示で、本文はだれにも表示されません。
次の手順で、Stripe と Vercel の設定をしてから公開してください。

## 1. Stripe でライトプランの商品と価格を作る

1. Stripe ダッシュボードの「商品カタログ」で、商品「ライトプラン」を作ります。
2. その商品に、次の2つの価格（継続課金）を作ります。
   - 月額 980円（税込）
   - 年額 9,800円（税込）
3. それぞれの価格ID（`price_` で始まる文字列）を控えておきます。

## 2. Payment Link を作り、完了後の戻り先を設定する

1. 月払い・年払いそれぞれの価格で Payment Link を作ります。
2. 各 Payment Link の「支払い後」の設定で「顧客をウェブサイトにリダイレクトする」を選び、次のURLを入れます。

   ```
   https://www.ifa-switch.com/members/activate?session_id={CHECKOUT_SESSION_ID}
   ```

   `{CHECKOUT_SESSION_ID}` はそのまま入力します（Stripe が実際の値に置き換えます）。
3. Payment Link のURL（`https://buy.stripe.com/...`）を控えておきます。

お支払いが終わると、このURLに戻ってきます。サイトが Stripe に問い合わせて、ライトプランの有効な契約であることを確かめてから、その端末をログイン状態にします。
（お支払いから48時間を過ぎた session_id ではログインできません。）

## 3. 読み取り専用の制限付きキーを作る

1. Stripe ダッシュボードの「開発者」→「APIキー」で「制限付きのキーを作成」を選びます。
2. 次の3つだけ「読み取り」にし、ほかはすべて「なし」にします。
   - Checkout Sessions
   - Customers
   - Subscriptions
3. 作ったキー（`rk_live_` で始まる文字列）を控えます。このキーはメールやチャットに貼らず、次の Vercel の画面に直接入力してください。

## 4. Vercel に環境変数を設定する

Vercel のプロジェクトの「Settings」→「Environment Variables」で、Production に次を設定します。

| 名前 | 値 |
| --- | --- |
| `MEMBER_COOKIE_SECRET` | 32文字以上のランダムな文字列。ターミナルで `openssl rand -base64 48` を実行して作れます |
| `STRIPE_SECRET_KEY` | 手順3の制限付きキー（`rk_live_...`） |
| `LITE_PRICE_IDS` | 手順1の価格IDを、カンマ区切りで（例：`price_aaa,price_bbb`） |

`ANTHROPIC_API_KEY`（AIチャット用）はすでに設定済みのはずです。

設定したら、再デプロイ（Redeploy）します。`MEMBER_COOKIE_SECRET` を変えると、全員がログアウトされます。

## 5. 動作を確認する

1. 本番の Payment Link で、ご自身のカードで実際に申し込みます（確認後、カスタマーポータルから解約・返金できます）。
2. お支払いのあと `/members?welcome=1` に戻り、「ライトプランでログイン中」と表示され、ガイドの本文が読めることを確かめます。
3. 別のブラウザ（シークレットウィンドウなど）で `/members` を開き、本文が表示されないことを確かめます。

## 6. 料金ページで申し込めるようにする

`src/lib/plans.ts` のライトプランを次のように変えて、公開します。

- `links.monthly` / `links.yearly` に、手順2の Payment Link のURLを入れる
- `status` を `"coming-soon"` から `"available"` に変える
- `note`（準備中の案内文）を削除する

## 仕組みのメモ

- ログイン状態は、署名付きのクッキー（35日間）で管理しています。会員ページを開くたびに期限が延びます。
- 最後の確認から24時間以上たっていたら、次に会員ページを開いたときに Stripe で契約がまだ有効かを確かめ直します。解約済みならログアウトされます。
- AIチャットは、ログイン中の会員は1日50問、それ以外は1日20問までです。
- 別の端末でのログイン（`/members/login`）は、まだメールでログイン用リンクを送る機能がありません。今は「ifa.switch@gmail.com までご連絡ください」と表示されます。
  メールアドレスの入力だけでログインさせると、他人になりすませてしまうため、ログイン用リンクをメールで送る仕組み（メール送信サービスが必要）を入れるまでは、この表示のままにしています。
